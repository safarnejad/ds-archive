جلسۀ بیستم: پرسش کمینۀ یک محدوده و درخت دکارتی

مطالعۀ بیشتر: خارج از مراجع

مسئلۀ پرسش کمینۀ یک محدوده

  • یک لیست A به طول n داده شده و هر بار کمینۀ یک محدودۀ A[j … k] از لیست پرسیده می‌شود (range minimum query یا RMQ).
  • هر راه‌حل را با سه معیار می‌سنجیم: زمان پیش‌پردازش، حافظۀ اضافه و زمان پاسخ به هر پرسش.

۱. راه‌حل ساده

  • هر بار کل محدوده را بررسی می‌کنیم. پیش‌پردازش O(1)، حافظۀ اضافه O(1) و پاسخ به پرسش O(n).
def rmq_naive(A, j, k):
  return min(A[j:k + 1])

۲. ایدۀ جذر

  • لیست را به قسمت‌های √nتایی افراز می‌کنیم و کمینۀ هر قسمت را در پیش‌پردازش حساب می‌کنیم. برای پاسخ، قسمت‌های کاملی را که داخل محدوده‌اند از این اطلاعات می‌خوانیم و دو تکۀ ناقص دو سر محدوده را عنصر به عنصر بررسی می‌کنیم.
  • پیش‌پردازش O(n)، حافظۀ اضافه O(√n) و پاسخ به پرسش O(√n).
def sqrt_build(A):
  b = max(1, int(len(A) ** 0.5))
  return b, [min(A[i:i + b]) for i in range(0, len(A), b)]

def sqrt_query(A, b, M, j, k):
  result = A[j]
  while j <= k and j % b != 0:
    result = min(result, A[j])
    j += 1
  while j + b - 1 <= k:
    result = min(result, M[j // b])
    j += b
  while j <= k:
    result = min(result, A[j])
    j += 1
  return result

۳. ایدۀ توان‌های ۲ (جدول پراکنده)

  • برای هر عنصر، قسمت‌هایی را در نظر می‌گیریم که با آن عنصر شروع می‌شوند و طول 2i دارند، و کمینۀ هر کدام را در پیش‌پردازش حساب می‌کنیم (جدول پراکنده یا sparse table).
  • پیش‌پردازش: هر قسمت به طول 2i از دو قسمت به طول 2i−1 تشکیل شده است:
    min A[j … j + 2i − 1] = min(min A[j … j + 2i−1 − 1], min A[j + 2i−1 … j + 2i − 1])
  • پاسخ به پرسش: اگر i = ⌊log2(k − j + 1)⌋، دو قسمت به طول 2i که یکی از j شروع و دیگری به k ختم می‌شود کل محدوده را می‌پوشانند (با هم‌پوشانی، که برای کمینه اشکالی ندارد):
    min A[j … k] = min(min A[j … j + 2i − 1], min A[k − 2i + 1 … k])
  • پیش‌پردازش O(n log n)، حافظۀ اضافه O(n log n) و پاسخ به پرسش O(1).
def sparse_build(A):
  M = [A[:]]
  i = 1
  while 2 ** i <= len(A):
    prev, h = M[i - 1], 2 ** (i - 1)
    M.append([min(prev[j], prev[j + h]) for j in range(len(A) - 2 ** i + 1)])
    i += 1
  return M

def sparse_query(M, j, k):
  i = (k - j + 1).bit_length() - 1
  return min(M[i][j], M[i][k - 2 ** i + 1])

۴ و ۵. راه‌حل‌های دیگر

  • ۴. درخت پاره‌خطی (جلسۀ ۲۱): پیش‌پردازش O(n)، حافظۀ اضافه O(n) و پاسخ به پرسش O(log n). مزیت آن این است که تغییر مقدار عناصر را هم پشتیبانی می‌کند.
  • ۵. راه‌حل بهینه که در این درس گفته نمی‌شود: پیش‌پردازش O(n)، حافظۀ اضافه O(n) و پاسخ به پرسش O(1).

درخت دکارتی

  • تعریف (یادآوری از جلسۀ ۱۹): در درخت دکارتی (Cartesian tree) یک آرایه، عنصر کمینه در ریشه است، زیردرخت چپ به صورت بازگشتی از عناصر سمت چپ آن و زیردرخت راست به صورت بازگشتی از عناصر سمت راست آن ساخته می‌شود.
  • پس درخت دکارتی از نظر مقدارها یک هرم کمینه و از نظر اندیس‌ها یک درخت دودویی جست‌وجوست: پیمایش میان‌ترتیب آن خود آرایه را می‌دهد.
  • مثال برای لیست [9, 3, 7, 1, 8, 12, 10, 20, 15, 18, 5]: ریشه ۱ است، زیردرخت چپ از [9, 3, 7] با ریشۀ ۳ و زیردرخت راست از [8, 12, 10, 20, 15, 18, 5] با ریشۀ ۵ ساخته می‌شود.
  • ساخت مستقیم بازگشتی در بدترین حالت O(n2) است (مثل مرتب‌سازی سریع روی آرایۀ مرتب).

ساخت درخت دکارتی در زمان خطی با پشته

  • عناصر را از چپ به راست اضافه می‌کنیم. مسیر راست درخت (از ریشه تا راست‌ترین رأس) را در یک پشته نگه می‌داریم.
  • برای عنصر جدید x از بالای پشته عناصر بزرگ‌تر از x را بیرون می‌آوریم. آخرین عنصری که بیرون آمد فرزند چپ x می‌شود و x فرزند راست عنصری می‌شود که بالای پشته مانده است (اگر پشته خالی شد، x ریشه است). سپس x را در پشته می‌گذاریم.
  • هر عنصر حداکثر یک بار وارد و یک بار از پشته خارج می‌شود، پس کل زمان O(n) است (تحلیل سرشکن، جلسۀ ۲۲).
  • کد زیر برای هر اندیس، اندیس پدر و فرزند چپ و راست را برمی‌گرداند (None یعنی وجود ندارد).
def cartesian_tree(A):
  n = len(A)
  parent, left, right = [None] * n, [None] * n, [None] * n
  stack = []
  for i in range(n):
    last = None
    while stack and A[stack[-1]] > A[i]:
      last = stack.pop()
    if last is not None:
      left[i] = last
      parent[last] = i
    if stack:
      right[stack[-1]] = i
      parent[i] = stack[-1]
    stack.append(i)
  return parent, left, right

تبدیل پرسش کمینۀ یک محدوده به پایین‌ترین جد مشترک

  • کمینۀ A[j … k] برابر مقدار پایین‌ترین جد مشترک (lowest common ancestor یا LCA) رأس‌های j و k در درخت دکارتی است.
  • دلیل: جد مشترک پایین‌ترین رأسی است که j و k در دو طرف آن (یا خود آن) قرار دارند. پس اندیس آن بین j و k است و چون کل زیردرختش (که محدوده را در بر می‌گیرد) از آن بزرگ‌تر است، کمینۀ محدوده است.
  • بنابراین هر داده‌ساختار برای LCA یک داده‌ساختار برای RMQ می‌دهد (و برعکس). کد زیر نسخۀ سادۀ این ایده است که با بالا رفتن از دو رأس، جد مشترک را در زمان ارتفاع درخت پیدا می‌کند.
def depth(parent, v):
  d = 0
  while parent[v] is not None:
    v = parent[v]
    d += 1
  return d

def lca(parent, u, v):
  du, dv = depth(parent, u), depth(parent, v)
  while du > dv:
    u, du = parent[u], du - 1
  while dv > du:
    v, dv = parent[v], dv - 1
  while u != v:
    u, v = parent[u], parent[v]
  return u

def rmq_lca(A, parent, j, k):
  return A[lca(parent, j, k)]
