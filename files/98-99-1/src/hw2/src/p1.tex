
\شروع‌مسئله [12]
 ثابت کنید مرتبه زمانی الگوریتم مرتب سازی درجی به صورت میانگین $\Theta(n^2)$ است.

\solution{

لم: تعداد جابجایی ها در مرتب سازی درجی برابر است با:
$$T(n) = \sum_{i = 0}^{n-1} max (0,i-A[i])$$
که $A[i]$ جایگاه عضو $i$ ام آرایه در آرایه مرتب شده است.
اثبات لم براحتی با استقرا روی $n$ قابل انجام است.

حال به اثبات مسئله می پردازیم:

طبق لم داریم:
$$E(T(n)) = \sum_{i = 0}^{n-1} E(max (0,i-A[i]))$$
چون $A[i]$  هر از یک از مقادیر 0 تا $n-1$ را با احتمال مساوی اخذ می کند پس داریم :
$$E(max(0,i-A[i])) = \sum_{j = 0}^{n-1} \frac{1}{n}max (0,i-j) = \frac{1}{n}\sum_{k = 1}^{i} k = \frac{i(i+1)}{2n}$$
پس داریم : 
$$E(T(n)) = \frac{1}{2n}\sum_{i = 0}^{n-1} (i^2+i) = \frac{(n+1)(2n+1)}{12} + \frac{n+1}{4} = \theta(n^2)$$
}
