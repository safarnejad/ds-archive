با استفاده از درخت بازگشت، پیچیدگی تابع $T(n)$ را در هر قسمت به دست آورید.
\شروع{زیرمسائل}
\زیرمسئله
$T(n) = 2T(n/2) + \Theta(nlogn)$

\زیرمسئله
$T(n) =3T(n/4) + 5n$

\زیرمسئله

\پایان{زیرمسائل}

\solution{
\begin{enumerate}
\item
$$T(n) = 2T(\frac{n}{2}) + \Theta(nlogn)$$
برای حل این سوال، همان روش درختی را که برای تحلیل اردر 
$$T(n) = 2T(\frac{n}{2}) + \Theta(n)$$
به کار بردیم را بنویسید. تنها تفاوتی که رخ می‌دهد، وجود تابع لگاریتم است که ابتدا با کران بالای 
$log(n)$
برای لگاریتم هر جمله، می‌توانید به اردر 
$O(nlog(n)^2)$
برسید. برای اثبات 
$\Omega(nlog(n)^2)$
کافی است که 
$\frac{log(n)}{2}$
مرحله‌ی اول را در نظر بگیرید و جای تابع لگاریتمی که در هر تابع ظاهر شده است، کران پایین
$log(\frac{n}{2^{\frac{log(n)}{2}}}) = log(\sqrt{n}) = \frac{log(n)}{2}$
را قرار دهید و نتیجه بگیرید که اردر تابع، از 
$\Omega(nlog(n)^2)$
است. پس در کل تابع از 
$\Theta(nlog(n)^2)$
است.
\item
$$T(n) = 3T(\frac{n}{4}) + 4n$$
$$T(n) = 4n + 3 * 4 * \frac{n}{4} + 3^2 * 4 * \frac{n}{16} + ... + 3 ^ {log_4{n}} * 4 * \frac{n}{4^{log_4(n)}}$$
$$T(n) = 4\sum_{i=1}^{log_4(n)}(\frac{3^i}{4^i}n) < T(n) = 4\sum_{i=1}^{\infty}(\frac{3^i}{4^i}n) = \Theta(n)$$
آخری تساوی‌ای که نوشته شده است، به کمک جمع جملات دنباله‌ی هندسی بدست آمده است.
\item
$$T(n) = 2T(n-1) + \Theta(n)$$
$$T(n) = 2T(n-1) + c_1 * n = 4T(n-2) + 2c_2(n-1) + c_1n = ... = \sum_1^{n}(c_i * 2^i * (n - i))$$
که چون جملات به شکل نمایی افزایش می‌یابند، اردر تابع مورد نظر، از اردر جمله‌ی آخر است که برابر است با 
$2^n$.
\end{enumerate}

}
