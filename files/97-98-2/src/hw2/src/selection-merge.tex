\begin{lstlisting}
def min_index(a, i, j):
	if i == j:
		return i
	k = min_index(a, i + 1, j)

	if a[i] < a[k]:
		return i
	else:
		return k

def selection_sort(a, n, index):
	if index == n:
		return -1
	k = min_index(a, index, n - 1)

	if k != index:
		a[k], a[index] = a[index], a[k]
	selection_sort(a, n, index + 1)

def main():
	arr = [32, 11, -5, 1, 7, 61, 43, 3]
	selection_sort(arr, len(arr), 0)
	
main()
\end{lstlisting}
	\setstretch{1.3}
\end{latin}

\زیرمسئله
یک مدل از مرتب‌سازی ادغامی (\متن‌لاتین{merge sort}) برای آرایۀ $A$ به صورت زیر می‌باشد: (منظور از 
$A[i\dots j]$
بخشی از آرایه است که بین 
$A[i]$
و
$A[j]$
(و شامل این دو عنصر) می‌باشد)

\شروع{فقرات}
\فقره اگر 
$n=1$
است، الگوریتم به پایان می‌رسد.
\فقره در غیر این صورت، قرار دهید
$k=\ceil{\frac{n}{3}}$.
\فقره به صورت بازگشتی 
$A[1\dots k]$
و
$A[k+1\dots n]$
را مرتب کنید.
\فقره دو زیرآرایۀ 
$A[1\dots k]$
و
$A[k+1\dots n]$
را ادغام کنید.

\پایان{فقرات}

ثابت کنید پیچیدگی زمانی این الگوریتم برابر است با 
$\mathcal{O}(n\log{}n)$
.
