\solution{
\شروع{زیرمسائل}
\زیرمسئله از حدس و استقرا برای حل این مسئله استفاده می‌کنیم.  $T \in \Theta(nlog(n))$ می‌تواند با توجه به رابطه بازگشتی حدس منطقی‌ای باشد. مانند قبل فرض می‌کنیم برای $b$ و $c$ و $n$ های کوچکتر از $m$ داریم:
$T(n) \leq bnlog(n) + c$
مانند قبل می‌خواهیم داشته باشیم:
$T(m) = T(\floor{\frac{m}{2}}) + T(\ceil{\frac{m}{2}}) + m \leq b(\floor{\frac{m}{2}}log(\floor{\frac{m}{2}}) + \ceil{\frac{m}{2}}log(\ceil{\frac{m}{2}})) + 2c + m \leq 
bmlog(m) + c$
$\Leftrightarrow b(\floor{\frac{m}{2}} +\ceil{\frac{m}{2}})log(\frac{m+1}{2}) + c + m \leq bmlog(m) = bmlog(\frac{m+1}{2}) + c + m \leq bmlog(m)$
$\Leftrightarrow 1 + \frac{c}{m} \leq blog(\frac{2m}{m+1})$
برای این که عبارت بالا برقرار باشد کافی است $c$ را منفی در نظر بگیریم و $b$ را به اندازه‌ی کافی بزرگ. در این صورت طبق استقرا برای هر $n$ خواهیم داشت:
$T(n) \leq bnlog(n) + c \Rightarrow T \in O(nlog(n))$
به همین صورت می‌توان ثابت کرد که $T \in \Omega(n)$. در نتیجه $T \in \Theta(n)$.
\زیرمسئله $n^{\log_b a} = n^{0.682}$
و چون 
$n^{0.6}$
از  
$n^{0.682}$
به صورت چند جمله ای  کوچکتر است پس در این حالت جواب 
$\theta(n^{0.682})$
است. (حالت اول قضیه اصلی)
\زیرمسئله $T(n) = T(n - 1) + \frac{1}{n}$
\زیرمسئله $T(n) = 3T(\frac{n}{3}) + \frac{n}{log(n)}$
\زیرمسئله $T(n) = 2T(\sqrt[3]{n}) + log(n)^2$
\پایان{زیرمسائل}
}
