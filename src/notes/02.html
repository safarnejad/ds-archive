تاریخچه و تعریف الگوریتم

  • تاریخچۀ الگوریتم‌ها: اولین الگوریتم‌ها دستورالعمل‌های تاریخی برای آشپزی، مراسم مذهبی و کشاورزی بودند. سپس ضرب اعداد توسط مصریان، جذر و تجزیۀ اعداد توسط بابلیان، الگوریتم اقلیدس و غربال اراتستن پیش از میلاد. حذف گاوسی و روشی برای حل برخی معادلات در چین، و سپس کتاب جبر و مقابلۀ خوارزمی که نام الگوریتم از نام او گرفته شده است. عصر جدید الگوریتم‌ها از حدود ۱۹۷۰ به بعد است.
  • تعریف الگوریتم، شبه‌کد و مدل محاسبات و رابطۀ آن‌ها با برنامه، زبان برنامه‌نویسی و کامپیوتر: برنامه با زبان برنامه‌نویسی نوشته می‌شود و کامپیوتر آن را اجرا می‌کند. به همین ترتیب الگوریتم (معادل برنامه) با شبه‌کد نوشته می‌شود و روی مدل محاسبات (معادل کامپیوتر) اجرا می‌شود.

مدل‌های محاسبات

  • مدل صفر: ماشین تورینگ.
  • مدل یک: ماشین دسترسی تصادفی (RAM) و ارتباط آن با حافظۀ RAM. در هر قدم:
    • تعداد ثابتی خانه از حافظه بارگذاری می‌کند،
    • تعداد ثابتی عملیات روی آن‌ها انجام می‌دهد،
    • و تعداد ثابتی خانه را در حافظه ذخیره می‌کند.
    • هر قدم یک واحد زمان می‌گیرد، بنابراین زمان الگوریتم برابر تعداد قدم‌های آن است.
    • تعریف کلمه (w) با حداقل اندازۀ log2 n بیت، تا بتوان با یک کلمه به هر خانۀ ورودی اشاره کرد، و ارتباط آن با محاسبۀ زمان الگوریتم‌ها.
  • مدل دو: ماشین اشاره‌گر. هر شیء تعداد ثابتی فیلد دارد که هر فیلد یا یک کلمه است یا یک اشاره‌گر به یک شیء دیگر.
    • با مدل RAM قابل پیاده‌سازی است و به زبان‌های شیءگرا نزدیک است.
    • اشاره‌گر در زبان‌های برنامه‌نویسی گاهی با نام reference وجود دارد.
  • مدل سه: ماشین پایتون. هر قدم یکی از دستورهای پایتون است، ولی دستورهای مختلف لزوماً زمان ثابتی نمی‌گیرند و در تحلیل الگوریتم باید به این نکته توجه کرد.
    • list در پایتون آرایه است و نه لیست پیوندی. L.append(x) زمان ثابت می‌گیرد (چگونگی آن در جلسۀ ۵ و جلسۀ ۲۲ توضیح داده می‌شود).
    • L1 + L2 و L1.extend(L2) در زمان O(n1 + n2 + 1) انجام می‌شوند. عدد ۱ برای حالتی است که هر دو لیست خالی باشند، چون زمان هیچ دستوری صفر نیست.
    • جست‌وجوی یک مقدار در لیست (x in L) زمان خطی دارد و len(L) زمان ثابت.
    • L.sort() زمان Θ(|L| log |L|) دارد که موضوع جلسات ۴ تا ۱۳ است.
    • str و tuple مشابه لیست هستند.
    • dict کلیدها را به مقادیر نگاشت می‌کند. زمان هر مقداردهی یا پرسیدن مقدار یک کلید با احتمال زیاد ثابت است که موضوع جلسات ۱۴ تا ۱۶ است. set هم مشابه dict است.
    • heapq صف اولویت را پیاده‌سازی می‌کند (جلسۀ ۷).
    • int اعداد بزرگ را ذخیره می‌کند و عملیات معمول را روی آن می‌توان انجام داد (کاربرد در رمزنگاری). جمع اعداد خطی است و مشابه روش مدرسه است، ولی ضرب از روش مدرسه سریع‌تر است (جلسۀ ۱۷).

تحلیل مجانبی

  • هدف از تحلیل الگوریتم: بررسی الگوریتم پیش از پیاده‌سازی از نظر زمان اجرا و حافظۀ مصرفی، و مقایسۀ الگوریتم‌ها با هم.
  • تحلیل در بدترین حالت، بهترین حالت و حالت میانگین (ورودی تصادفی است و میانگین زمان اجرا حساب می‌شود).
  • تعریف نمادها:
    Θ(g) = { f : ∃ c1, c2, n0 > 0, ∀n ≥ n0 : 0 ≤ c1g(n) ≤ f(n) ≤ c2g(n) }
    O(g) = { f : ∃ c, n0 > 0, ∀n ≥ n0 : 0 ≤ f(n) ≤ c g(n) }
    Ω(g) = { f : ∃ c, n0 > 0, ∀n ≥ n0 : 0 ≤ c g(n) ≤ f(n) }
    o(g) = { f : ∀c > 0, ∃n0, ∀n ≥ n0 : 0 ≤ f(n) < c g(n) }
    ω(g) = { f : ∀c > 0, ∃n0, ∀n ≥ n0 : 0 ≤ c g(n) < f(n) }
  • اگر f = Θ(g)، تابع g کران بسته مجانبی برای f است، و به همین ترتیب O کران بالا و Ω کران پایین مجانبی است.
  • تشبیه به مقایسۀ اعداد: O ≈ ≤، Ω ≈ ≥، Θ ≈ =، o ≈ < و ω ≈ >.
  • خواص:
    • تراگذری: اگر f = O(g) و g = O(h) آنگاه f = O(h) (برای همۀ نمادها).
    • بازتابی: f = Θ(f) (برای O، Ω و Θ).
    • تقارن: فقط Θ متقارن است.
    • تقارن ترانهاده: f = O(g) ⇔ g = Ω(f) و f = o(g) ⇔ g = ω(f).
