• یادآوری ترای و درخت پسوندی از جلسۀ ۱۸.

آرایۀ پسوندی

  • اگر پسوندهای یک رشته را به ترتیب لغت‌نامه‌ای مرتب کنیم، دنبالۀ اندیس‌های شروع پسوندهای مرتب‌شده آرایۀ پسوندی (suffix array) را تشکیل می‌دهد.
  • مثال: آرایۀ پسوندی banana$ برابر [6, 5, 3, 1, 0, 4, 2] است ($ از همۀ حروف کوچک‌تر است).
  • می‌توان نشان داد آرایۀ پسوندی معادل درخت پسوندی است و با این حال ساده‌تر و فشرده‌تر از آن است. ساختار درخت پسوندی با نگاه به آن مشخص است ولی برای آرایۀ پسوندی این‌طور نیست.
  • ساده‌ترین روش ساخت: پسوندها را مستقیم مرتب کنیم. هر مقایسه O(n) طول می‌کشد و کل زمان O(n2 log n) است.
def suffix_array_naive(t):
  return sorted(range(len(t)), key=lambda i: t[i:])

آرایۀ طولانی‌ترین پیشوند مشترک

  • در آرایۀ کمکی طولانی‌ترین پیشوند مشترک (LCP) برای هر دو پسوند متوالی در آرایۀ پسوندی، طول طولانی‌ترین پیشوند مشترک آن‌ها را ذخیره می‌کنیم.
  • این آرایه در زمان O(|t|) ساخته می‌شود (الگوریتم کاسای). نکتۀ اصلی: اگر پسوند i با پسوند قبلی خود در آرایۀ پسوندی h حرف مشترک داشته باشد، پسوند i + 1 با پسوند قبلی خود دست کم h − 1 حرف مشترک دارد. پس h در کل حداکثر 2n بار تغییر می‌کند.
  • در کد زیر lcp[r] طول پیشوند مشترک پسوندهای sa[r - 1] و sa[r] است و lcp[0] = 0.
def lcp_array(t, sa):
  n = len(t)
  rank = [0] * n
  for r in range(n):
    rank[sa[r]] = r
  lcp = [0] * n
  h = 0
  for i in range(n):
    if rank[i] > 0:
      j = sa[rank[i] - 1]
      while i + h < n and j + h < n and t[i + h] == t[j + h]:
        h += 1
      lcp[rank[i]] = h
      if h > 0:
        h -= 1
    else:
      h = 0
  return lcp

تطابق رشته‌ها با آرایۀ پسوندی

  • همۀ وقوع‌های s در t پسوندهایی‌اند که با s شروع می‌شوند و در آرایۀ پسوندی کنار هم قرار دارند. این بازه را با دو جست‌وجوی دودویی پیدا می‌کنیم.
  • بدون استفاده از LCP زمان هر جست‌وجو O(|s| log |t|) است.
  • با استفاده از LCP و داشتن کمینۀ هر زیربازه از آن (جلسۀ ۲۰) می‌توان این زمان را به O(|s| + log |t|) کاهش داد.
def search(t, sa, s):
  lo, hi = 0, len(sa)
  while lo < hi:
    mid = (lo + hi) // 2
    if t[sa[mid]:sa[mid] + len(s)] < s:
      lo = mid + 1
    else:
      hi = mid
  first, hi = lo, len(sa)
  while lo < hi:
    mid = (lo + hi) // 2
    if t[sa[mid]:sa[mid] + len(s)] == s:
      lo = mid + 1
    else:
      hi = mid
  return sorted(sa[first:lo])

تبدیل درخت و آرایۀ پسوندی به همدیگر

  • الف. درخت پسوندی به آرایۀ پسوندی: با پیمایش درخت (مشابه پیمایش میان‌ترتیب، با بررسی فرزندان به ترتیب حروف) پسوندها را به ترتیب در برگ‌ها می‌بینیم و آرایۀ پسوندی را می‌سازیم.
  • ب. آرایۀ پسوندی به درخت پسوندی: از درخت دکارتی آرایۀ LCP استفاده می‌کنیم.
    • درخت دکارتی یک آرایه: عنصر کمینه در ریشه قرار می‌گیرد، زیردرخت چپ به صورت بازگشتی از عناصر سمت چپ آن و زیردرخت راست به صورت بازگشتی از عناصر سمت راست آن ساخته می‌شود. ساخت آن در زمان خطی در جلسۀ ۲۰ می‌آید.
    • این‌جا اگر چند عنصر کمینه داشته باشیم، همه را در ریشه می‌گذاریم و آرایه به چند قسمت تقسیم می‌شود. در این صورت درخت دیگر دودویی نیست.
    • با این شرط، عدد هر رأس درخت دکارتی LCP برابر عمق حرفی (تعداد حروف مسیر از ریشه) یک رأس داخلی درخت پسوندی است و ساختار دو درخت یکی است. بنابراین می‌توان پسوندها را به ترتیب آرایۀ پسوندی در این درخت درج کرد و درخت پسوندی را ساخت.

ساخت آرایۀ پسوندی

  • روش‌های خطی متعددی وجود دارد. این‌جا دو روش با زمان O(|t| log2 |t|) و O(|t| log |t|) را می‌گوییم.
  • روش اول، مرتب کردن پسوندها و مقایسه با درهم‌سازی غلتان (جلسۀ ۱۵):
    • با محاسبۀ درهم‌سازی همۀ پیشوندهای رشته در پیش‌پردازش، درهم‌سازی هر زیررشته (با تفاضل درهم‌سازی دو پیشوند با ضریب مناسب) در O(1) به دست می‌آید.
    • با جست‌وجوی دودویی روی طول پیشوند مشترک، هر دو زیررشته در O(log |t|) مقایسه می‌شوند.
    • با یک مرتب‌سازی مقایسه‌ای با O(|t| log |t|) مقایسه، کل زمان O(|t| log2 |t|) است.
  • روش دوم، تکنیک دو برابر کردن (توان‌های ۲):
    • همان‌طور که در تبدیل باروز-ویلر (پایین‌تر) می‌بینیم، وقتی رشته به $ ختم شود ترتیب پسوندها همان ترتیب چرخش‌های رشته است.
    • در مرحلۀ iاُم چرخش‌ها را بر اساس 2i حرف اولشان مرتب می‌کنیم. هر چرخش با طول 2i+1 از دو نیمۀ به طول 2i تشکیل شده که رتبۀ هر دو از مرحلۀ قبل معلوم است، پس هر مقایسه در O(1) انجام می‌شود.
    • بعد از ⌈log2 n⌉ مرحله کار تمام است. با مرتب‌سازی مقایسه‌ای زمان کل O(|t| log2 |t|) و با مرتب‌سازی مبنایی (جلسۀ ۱۳) O(|t| log |t|) است.
def suffix_array(t):  # t ends with '$'
  n = len(t)
  rank = [ord(c) for c in t]
  sa = list(range(n))
  k = 1
  while True:
    key = lambda i: (rank[i], rank[(i + k) % n])
    sa.sort(key=key)
    new = [0] * n
    for r in range(1, n):
      new[sa[r]] = new[sa[r - 1]] + (key(sa[r]) != key(sa[r - 1]))
    rank = new
    if rank[sa[-1]] == n - 1:
      return sa
    k *= 2

کاربردهای آرایۀ پسوندی

  • چون آرایۀ پسوندی با درخت پسوندی معادل است، همۀ کاربردهای درخت پسوندی این‌جا هم وجود دارد و بسیاری از آن‌ها مستقیماً پیاده‌سازی می‌شوند.
  • مثلاً تعداد زیررشته‌های ناتهی متفاوت یک رشته به طول n (بدون $) برابر است با
    n(n + 1)/2 − Σi LCP[i]
    چون هر پسوند به اندازۀ طولش پیشوند دارد و LCP[i] تا از آن‌ها قبلاً شمرده شده‌اند.
  • طولانی‌ترین زیررشتۀ تکراری: بیشینۀ آرایۀ LCP.
def distinct_substrings(t):
  sa = suffix_array_naive(t)
  n = len(t)
  return n * (n + 1) // 2 - sum(lcp_array(t, sa))

تبدیل باروز-ویلر

  • اگر جلوی هر خانۀ آرایۀ پسوندی، رشتۀ چرخش‌یافته‌ای را بنویسیم که از همان مکان شروع می‌شود، حروف آخر این سطرها تبدیل باروز-ویلر (Burrows-Wheeler transform) رشته را تشکیل می‌دهند. یعنی حرف آخر هر سطر t[sa[r] - 1] است.
  • مثال: تبدیل banana$ برابر annb$aa است.
  • نکتۀ جالب این است که این تبدیل وارون‌پذیر است و از روی آن خود رشته (و در نتیجه آرایۀ پسوندی) بازسازی می‌شود.
  • روش وارون کردن: اگر i ستون اول جدول چرخش‌های مرتب را داشته باشیم، تبدیل را به عنوان ستون قبل از آن‌ها می‌گذاریم (چرخش هر سطر) و سطرها را مرتب می‌کنیم. این‌طور i + 1 ستون اول به دست می‌آید. بعد از n مرحله کل جدول را داریم و رشته سطری است که به $ ختم می‌شود.
  • بسیاری از روش‌های فشرده‌سازی (مثل bzip2) از این تبدیل استفاده می‌کنند زیرا اغلب حروف مشابه را کنار هم قرار می‌دهد. ولی لزوماً این‌طور نیست، مثلاً BWT(appelee$) = e$elpepa.
def bwt(t):  # t ends with '$'
  sa = suffix_array(t)
  return ''.join(t[i - 1] for i in sa)

def inverse_bwt(b):
  table = [''] * len(b)
  for _ in range(len(b)):
    table = sorted(b[r] + table[r] for r in range(len(b)))
  for row in table:
    if row[-1] == '$':
      return row
