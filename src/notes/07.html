واسط صف اولویت

  • صف اولویت یک واسط مجموعه‌ای است که در آن کلید همان اولویت است. (واسط دنباله‌ای اندیس دارد و واسط مجموعه‌ای کلید.)
  • عملیات:
    • len()
    • insert(v)
    • find_max() و delete_max()، یا در صف اولویت کمینه find_min() و delete_min()
  • برخی کاربردهای صف اولویت: مرتب‌سازی و الگوریتم دکسترا (جلسۀ ۲۸).
  • مرتب‌سازی با صف اولویت: همۀ اعضا را درج می‌کنیم و سپس n بار بیشینه را حذف می‌کنیم و از آخر آرایه می‌چینیم (یا با صف کمینه از اول آرایه).
def max_pq_sort(A):
  Q = []
  for v in A:
    insert(Q, v)
  for i in range(len(A)):
    A[len(A) - 1 - i] = delete_max(Q)
  • داده‌ساختارهایی که تا الان گفته شدند برای صف اولویت خوب نیستند:
    • آرایۀ نامرتب: insert در O(1) (سرشکن) ولی find_max و delete_max در O(n).
    • آرایۀ مرتب: find_max و delete_max در O(1) ولی insert در O(n).
  • هرم دودویی: len در O(1)، insert در O(log n)، find_max در O(1) و delete_max در O(log n).
  • داده‌ساختارهای دیگری مثل هرم فیبوناچی هم برای صف اولویت وجود دارند: insert و find_max در O(1) و delete_max به صورت سرشکن در O(log n). افزایش کلید هم در آن سرشکن O(1) است و به همین دلیل دکسترا را از نظر تئوری سریع‌تر می‌کند. ولی ثابت‌های آن بزرگ است و در عمل از هرم دودویی استفاده می‌شود؛ هرم فیبوناچی بیشتر ارزش نظری دارد.

هرم دودویی

  • هرم بیشینه (max-heap) یک درخت دودویی تقریباً کامل (جلسۀ ۶) است که به صورت آرایه ذخیره می‌شود و با همان parent(i)، left(i) و right(i) پیمایش می‌شود. به آن درخت نیمه‌مرتب (partially ordered tree) هم می‌گویند.
  • خاصیت هرم بیشینۀ درختی: کلید هر رأس از کلید همۀ رئوس زیردرختش کوچک‌تر نیست.
  • خاصیت هرم بیشینۀ رأسی: کلید هر رأس از کلید فرزندانش کوچک‌تر نیست. این دو خاصیت معادل‌اند (با استقرا روی ارتفاع). پس بیشینه در ریشه است.
  • ارتفاع هرم با n عضو ⌊log2 n⌋ است، پس درج و حذف در O(log n) انجام می‌شوند.
  • در همۀ کدهای پایین Q یک هرم بیشینه است که به صورت آرایه (لیست پایتون) ذخیره شده است.
def parent(i):
  return (i - 1) // 2

def left(i):
  return 2 * i + 1

def right(i):
  return 2 * i + 2

def find_max(Q):
  return Q[0]
  • درج با max_heapify_up: عضو جدید را به عنوان برگ در آخر آرایه اضافه می‌کنیم و تا وقتی از پدرش بزرگ‌تر است با پدرش جابه‌جا می‌کنیم (به سمت ریشه حرکت می‌کنیم).
def insert(Q, v):
  Q.append(v)
  max_heapify_up(Q, len(Q) - 1)

def max_heapify_up(Q, i):
  if i > 0 and Q[i] > Q[parent(i)]:
    Q[i], Q[parent(i)] = Q[parent(i)], Q[i]
    max_heapify_up(Q, parent(i))
  • افزایش کلید یک عضو هم به همین شکل است: کلید را افزایش می‌دهیم و max_heapify_up را صدا می‌زنیم.
def increase_key(Q, i, v):
  if v < Q[i]:
    raise ValueError("new key is smaller than the current key")
  Q[i] = v
  max_heapify_up(Q, i)
  • حذف بیشینه با max_heapify_down: ریشه را با آخرین برگ جابه‌جا و آن برگ را حذف می‌کنیم. سپس ریشه را تا وقتی از یکی از فرزندانش کوچک‌تر است با بزرگ‌ترین فرزندش جابه‌جا می‌کنیم. پارامتر n اندازۀ هرم است (برای مرتب‌سازی هرمی لازم می‌شود).
def max_heapify_down(Q, i, n):
  j = i
  if left(i) < n and Q[left(i)] > Q[j]:
    j = left(i)
  if right(i) < n and Q[right(i)] > Q[j]:
    j = right(i)
  if j != i:
    Q[i], Q[j] = Q[j], Q[i]
    max_heapify_down(Q, j, n)

def delete_max(Q):
  Q[0], Q[-1] = Q[-1], Q[0]
  v = Q.pop()
  max_heapify_down(Q, 0, len(Q))
  return v

ساخت هرم

  • ساخت هرم با n درج متوالی O(n log n) طول می‌کشد.
  • راه بهتر: برگ‌ها خودشان هرم‌اند. از آخرین رأس داخلی تا ریشه روی هر رأس max_heapify_down را اجرا می‌کنیم. وقتی به رأس i می‌رسیم هر دو زیردرختش هرم‌اند، پس بعد از آن زیردرخت i هم هرم است.
def build_heap(A):
  for i in range(len(A) // 2 - 1, -1, -1):
    max_heapify_down(A, i, len(A))
  • تحلیل زمانی ساخت هرم در O(n): max_heapify_down روی رأسی به ارتفاع h زمان O(h) می‌برد و حداکثر ⌈n/2h+1⌉ رأس با ارتفاع h داریم، پس
    ∑h=0⌊log n⌋ ⌈n/2h+1⌉ · O(h) = O(n ∑h≥0 h/2h) = O(n)
    چون ∑h≥0 h/2h = 2. شهود: بیشتر رئوس نزدیک برگ‌ها هستند و کار کمی دارند.

مرتب‌سازی هرمی

  • آرایه را در جای خودش به هرم بیشینه تبدیل می‌کنیم. سپس هر بار بیشینه (ریشه) را با آخرین عضو هرم جابه‌جا می‌کنیم، اندازۀ هرم را یکی کم می‌کنیم و max_heapify_down را روی ریشه اجرا می‌کنیم.
  • زمان O(n log n) و حافظۀ اضافۀ O(1) (درجا). (با هرم کمینه هم می‌توان مرتب کرد: کمینه‌ها را به ترتیب حذف می‌کنیم.)
def heap_sort(A):
  build_heap(A)
  for n in range(len(A) - 1, 0, -1):
    A[0], A[n] = A[n], A[0]
    max_heapify_down(A, 0, n)
