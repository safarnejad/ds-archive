• موضوع درس: روندهای بهینه برای حل مسائل با مقیاس نسبتاً بزرگ، در کنار تحلیل و طراحی این روندها.
  • معیارهای بهینه‌بودن: درستی، سرعت، فضای کم، کلی بودن، سادگی و خلاقانه بودن.
  • معیار بزرگ بودن در طول زمان فرق کرده است. مثال‌هایی از داده‌های بزرگ: نقشه‌های شهری و بین‌شهری، ژنوم انسان و شبکه‌های اجتماعی.
  • تعریف مقیاس‌پذیری یک روش.
  • تعریف «تست زمان» و علت قدیمی بودن برخی مطالب درس.
  • تأکید این درس بر تحلیل است و درس بعدی (طراحی الگوریتم‌ها) بیشتر به طراحی می‌پردازد.
  • مرور عناوین درس: تفکر الگوریتمی، مرتب‌سازی، درخت‌ها، درهم‌سازی، اعداد بزرگ، دیگر داده‌ساختارها، گراف‌ها و مباحث پیشرفته.

مسئلۀ پیدا کردن قله

  • قله خانه‌ای است که از خانه‌های مجاورش (در صورت وجود) بزرگ‌تر یا مساوی باشد. می‌خواهیم در یک آرایۀ یک‌بعدی یا دوبعدی یک قله (بیشینۀ محلی) پیدا کنیم.
  • هر آرایه حتماً قله دارد: بزرگ‌ترین خانه یک قله است.

آرایۀ یک‌بعدی

  • راه اول: بررسی تمام خانه‌ها. n خانه دیده می‌شود.
  • راه دوم: شروع از یک سمت یا وسط آرایه و حرکت تا جایی که به قله برسیم. حداکثر n خانه دیده می‌شود.
  • راه سوم: خانۀ وسط را نگاه می‌کنیم. اگر قله نبود، یکی از همسایه‌هایش از آن بزرگ‌تر است و در همان سمت حتماً قله‌ای هست، پس مسئله نصف می‌شود. حداکثر حدود 3 log2 n خانه پرسیده می‌شود.
def peak_1d(A, lo, hi):
  mid = (lo + hi) // 2
  if mid > lo and A[mid - 1] > A[mid]:
    return peak_1d(A, lo, mid - 1)
  if mid < hi and A[mid + 1] > A[mid]:
    return peak_1d(A, mid + 1, hi)
  return mid

آرایۀ دوبعدی n × n

  • راه اول: از یک خانه شروع کنیم و هر بار به بزرگ‌ترین خانۀ مجاور برویم. ممکن است نزدیک به نصف خانه‌ها دیده شوند.
  • راه دوم: در ستون وسط با الگوریتم یک‌بعدی قله‌ای پیدا کنیم و در سطر آن نیز یک قلۀ یک‌بعدی پیدا کنیم و آن را خروجی دهیم. الگوریتم سریع ولی غلط است. درست بودن بهتر است یا سریع بودن؟ معرفی الگوریتم‌های مکاشفه‌ای.
  • راه سوم: بیشینۀ هر ستون را پیدا کرده و در یک لیست بریزیم و سپس قلۀ این لیست را با راه سوم یک‌بعدی پیدا کنیم. حدود n2 خانه دیده می‌شود.
  • راه چهارم: بیشینۀ هر ستون را فقط هنگام نیاز حساب کنیم. حدود 3n log2 n خانه دیده می‌شود.
  • راه پنجم: در ستون وسط عنصر بیشینه را پیدا می‌کنیم. اگر قله نبود، همسایۀ بزرگ‌تر آن در چپ یا راست است و مسئله را در همان نیمه ادامه می‌دهیم. حدود n log2 n خانه دیده می‌شود.
  • راه ششم: الگوریتم قبلی را یک‌بار روی ستون‌ها و یک‌بار روی سطرها اجرا کنیم (به تناوب نیمه کردن ستون‌ها و سطرها). حدود O(n) خانه دیده می‌شود.
def peak_2d(A, lo, hi):
  mid = (lo + hi) // 2
  i = max(range(len(A)), key=lambda r: A[r][mid])  # max of the middle column
  if mid > lo and A[i][mid - 1] > A[i][mid]:
    return peak_2d(A, lo, mid - 1)
  if mid < hi and A[i][mid + 1] > A[i][mid]:
    return peak_2d(A, mid + 1, hi)
  return i, mid
