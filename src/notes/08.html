مسئلۀ رزرو باند فرودگاه

  • یک باند فرودگاه داریم و مجموعه‌ای از زمان‌های فرود رزروشده. می‌خواهیم:
    • برای یک زمان درخواستی t چک کنیم که در مجموعه تا k دقیقه قبل و بعد از آن فرودی نباشد و در این صورت t را به مجموعه اضافه کنیم؛
    • یک زمان را پس از فرود از مجموعه حذف کنیم.
  • به صورت دقیق‌تر این یک واسط مجموعۀ پویای مرتب است (جلسۀ ۵): insert، delete، find_next و find_prev.
  • بررسی داده‌ساختارهای قبلی:
    • آرایۀ نامرتب: درج سریع ولی چک کردن O(n).
    • آرایۀ مرتب: چک کردن با جست‌وجوی دودویی O(log n) ولی درج و حذف O(n).
    • هرم: پیدا کردن عضو بعدی و قبلی را پشتیبانی نمی‌کند.

درخت دودویی جست‌وجو

  • رویکرد تقسیم و حل: جست‌وجوی دودویی در حالت پویا.
  • خاصیت درخت دودویی جست‌وجو: کلید هر رأس از کلید همۀ رئوس زیردرخت چپش بزرگ‌تر یا مساوی و از کلید همۀ رئوس زیردرخت راستش کوچک‌تر یا مساوی است. برخلاف هرم، این خاصیت معادل رأسی و محلی (فقط با فرزندان) ندارد.
  • چون فرض تقریباً کامل بودن درخت را نداریم، برای هر رأس یک شیء درنظر می‌گیریم شامل کلید و اشاره‌گرهایی به والد، فرزند چپ و فرزند راست (node.key، node.parent، node.left و node.right). در مدل RAM هر اشاره‌گر یک کلمه است. new_node(...) یک رأس جدید با این ویژگی‌ها می‌سازد.
  • تعداد درخت‌های دودویی جست‌وجوی متفاوت با n کلید متمایز برابر nامین عدد کاتالان است.

پیدا کردن

  • اگر دنبال k هستیم و در رأس node هستیم: اگر کلید آن بیشتر از k بود به فرزند چپ می‌رویم، اگر کمتر بود به فرزند راست و اگر برابر بود رأس را پیدا کرده‌ایم.
def find(node, k):
  if node is None or node.key == k:
    return node
  if k < node.key:
    return find(node.left, k)
  return find(node.right, k)
  • کمینه: تا وقتی رأس فعلی فرزند چپ دارد به فرزند چپ می‌رویم.
def find_min(node):
  if node.left:
    return find_min(node.left)
  return node
  • عضو بعدی (successor) رأس node: اگر فرزند راست دارد، کمینۀ زیردرخت راست. وگرنه به سمت ریشه بالا می‌رویم تا به رأسی برسیم که از فرزند چپش به آن رسیده‌ایم.
def successor(node):
  if node.right:
    return find_min(node.right)
  while node.parent and node is node.parent.right:
    node = node.parent
  return node.parent

درج و حذف

  • درج: مثل find پایین می‌رویم و جایی که فرزند وجود ندارد رأس جدید را می‌گذاریم. (insert روی درخت ناتهی صدا زده می‌شود و رأس جدید را برمی‌گرداند.)
def insert(node, k):
  if k <= node.key:
    if node.left:
      return insert(node.left, k)
    node.left = new_node(key=k, parent=node, left=None, right=None)
    return node.left
  else:
    if node.right:
      return insert(node.right, k)
    node.right = new_node(key=k, parent=node, left=None, right=None)
    return node.right
  • حذف یک رأس و بررسی همۀ حالت‌ها. T.root ریشۀ درخت است (چون ممکن است ریشه حذف شود):
    • رأس دو فرزند دارد: کلید عضو بعدی (کمینۀ زیردرخت راست) را در آن می‌گذاریم و آن عضو را حذف می‌کنیم؛ عضو بعدی فرزند چپ ندارد.
    • رأس فقط فرزند چپ یا فقط فرزند راست دارد: آن فرزند جایگزینش می‌شود.
    • رأس برگ است: آن را از والدش جدا می‌کنیم.
def delete(T, node):
  if node.left and node.right:
    succ = find_min(node.right)
    node.key = succ.key
    delete(T, succ)
  else:
    child = node.left or node.right
    if child:
      child.parent = node.parent
    if node.parent is None:
      T.root = child
    elif node is node.parent.left:
      node.parent.left = child
    else:
      node.parent.right = child
  • حذف کمینه حالت خاصی از همین است: delete(T, find_min(T.root)).
  • همۀ این عملیات را می‌توان به صورت غیربازگشتی هم با یک حلقه نوشت.

زمان اجرا و ارتفاع

  • همۀ این عملیات در O(h) انجام می‌شوند که h ارتفاع درخت است.
  • ارتفاع درخت با n رأس همیشه حداقل ⌊log2 n⌋ است، ولی ممکن است n − 1 باشد: مثلاً اگر اعضا به ترتیب صعودی درج شوند درخت یک مسیر می‌شود.
  • اگر درخت با درج n عضو به ترتیب تصادفی ساخته شود، امید ارتفاع آن O(log n) است (در کلاس اثبات شد).
  • موضوع دو جلسۀ بعد درخت‌های دودویی جست‌وجویی است که ارتفاعشان همیشه O(log n) است و به اصطلاح متوازن‌اند.

مرتب‌سازی با درخت دودویی جست‌وجو

  • درخت دودویی جست‌وجو مجموعه را مرتب نگه می‌دارد: پیمایش میان‌ترتیب (جلسۀ ۶) اعضا را در O(n) به ترتیب خروجی می‌دهد.
  • پس با n درج و یک پیمایش میان‌ترتیب مرتب می‌کنیم: زمان O(n h) که در بدترین حالت Θ(n2) است.
def in_order(node, out):
  if node:
    in_order(node.left, out)
    out.append(node.key)
    in_order(node.right, out)

def bst_sort(A):
  root = None
  for k in A:
    if root is None:
      root = new_node(key=k, parent=None, left=None, right=None)
    else:
      insert(root, k)
  out = []
  in_order(root, out)
  return out

درخت دودویی جست‌وجوی افزوده

  • برای پیدا کردن مرتبۀ هر عضو (rank())، در هر رأس تعداد اعضای زیردرختش را نگه می‌داریم و موقع درج و حذف آن را به‌روز می‌کنیم.
  • rank(k): مثل find پایین می‌رویم و هر بار که به راست می‌رویم، یک به‌علاوۀ اندازۀ زیردرخت چپ رأس فعلی را جمع می‌کنیم. در پایان اندازۀ زیردرخت چپ رأس پیداشده به‌علاوۀ یک را اضافه می‌کنیم.
  • افزودن اطلاعاتی از این دست به درخت دودویی جست‌وجو بسیار پرکاربرد است؛ جزئیات در جلسۀ ۲۱.
