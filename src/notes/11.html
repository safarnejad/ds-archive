مرتب‌سازی سریع

  • مرتب‌سازی سریع (quicksort) را هوآر در سال ۱۹۶۲ منتشر کرد.
  • حافظۀ اضافۀ آن Θ(1) است به‌علاوۀ پشتۀ اجرای بازگشتی که عمق آن به طور میانگین O(log n) است. از این جنبه از مرتب‌سازی ادغامی (جلسۀ ۴) بهتر است.
  • در عمل حدود دو برابر سریع‌تر از مرتب‌سازی ادغامی است.
  • مرتب‌سازی مورد استفاده در سی‌پلاس‌پلاس و جاوا (در جاوا برای مرتب کردن اعداد و نه اشیا) بر پایۀ مرتب‌سازی سریع است.
  • مرتب‌سازی سریع هم بر اساس تقسیم و حل است، ولی قسمت عمدۀ کار آن در مرحلۀ تقسیم انجام می‌شود. در مرتب‌سازی ادغامی تقسیم ساده و ادغام پرکار است؛ در مرتب‌سازی سریع تقسیم پرکار است و ادغام لازم نیست. حل در هر دو بازگشتی است.

مراحل الگوریتم

  • ورودی: آرایۀ A[0 … n − 1] به طول n. خروجی: آرایۀ مرتب‌شدۀ A.
  • مرحلۀ صفر: انتخاب یک عنصر لولا (pivot) به نام x از A.
  • مرحلۀ اول (تقسیم): تقسیم A به سه قسمت L (عناصر کوچک‌تر از x)، E (عناصر برابر با x) و G (عناصر بزرگ‌تر از x).
  • مرحلۀ دوم (حل): مرتب‌سازی L و G به صورت بازگشتی.
  • مرحلۀ سوم (ادغام): لازم نیست.
  • مسئلۀ اصلی این است که لولا را چطور انتخاب کنیم تا اندازۀ L و G متوازن باشد. اگر نامتوازن باشند زمان اجرا Θ(n2) می‌شود.
  • تقسیم درجا: با یک بار حرکت روی آرایه، عناصر کوچک‌تر از لولا را به ابتدای آرایه می‌بریم و لولا را بعد از آن‌ها می‌گذاریم. لولای تصادفی را قبل از تقسیم با عنصر آخر جابه‌جا می‌کنیم.
import random

def partition(A, lo, hi):
  x = A[hi]
  i = lo
  for j in range(lo, hi):
    if A[j] < x:
      A[i], A[j] = A[j], A[i]
      i += 1
  A[i], A[hi] = A[hi], A[i]
  return i

def quick_sort(A, lo=0, hi=None):
  if hi is None:
    hi = len(A) - 1
  if lo < hi:
    r = random.randint(lo, hi)
    A[r], A[hi] = A[hi], A[r]
    p = partition(A, lo, hi)
    quick_sort(A, lo, p - 1)
    quick_sort(A, p + 1, hi)
  • این تقسیم عناصر برابر با لولا را جدا نمی‌کند، پس اگر عناصر تکراری زیاد باشند بهتر است تقسیم سه‌قسمتی L, E, G را درجا پیاده کنیم.

انواع مرتب‌سازی سریع

  • ۱. مرتب‌سازی سریع پایه‌ای: عنصر اول یا آخر آرایه را لولا می‌گیرد. در بدترین حالت (وقتی آرایه صعودی یا نزولی باشد) زمان اجرای آن Θ(n2) است.
    • یک راه این است که عنصر وسط را لولا بگیریم. مشکل آرایۀ صعودی و نزولی حل می‌شود، اما حالت‌های بد دیگری هنوز وجود دارند.
    • راه بهتر به هم ریختن تصادفی (shuffle) ورودی قبل از اجرای الگوریتم است.
  • ۲. مرتب‌سازی سریع با انتخاب هوشمندانۀ لولا: میانه را با الگوریتم خطی (میانۀ میانه‌ها، پایین‌تر) پیدا می‌کنیم و لولا می‌گیریم.
    • زمان اجرا در بدترین حالت: T(n) = 2T(n/2) + Θ(n) = Θ(n log n).
    • متأسفانه ضریب این روش زیاد است و به مرتب‌سازی ادغامی می‌بازد! (زمان اجرای آن حدود دو برابر مرتب‌سازی ادغامی است.)
  • ۳. مرتب‌سازی سریع تصادفی: لولا را به صورت تصادفی (با احتمال مساوی بین عناصر A) انتخاب می‌کنیم (کد بالا).
    • بسیار ساده و در عین حال کارا.
    • همیشه درست مرتب می‌کند، ولی زمان اجرای آن با انتخاب لولا کم و زیاد می‌شود؛ پس یک الگوریتم لاس‌وگاس است (پایین‌تر).
    • امید ریاضی زمان اجرای آن برای هر ورودی دلخواه Θ(n log n) است. برای اثبات اصلی به فصل ۷ کتاب CLRS مراجعه کنید. ما همین زمان را برای مرتب‌سازی سریع تصادفی وسواسی اثبات می‌کنیم.

الگوریتم‌های تصادفی

  • تعریف: الگوریتم‌هایی که یک عدد تصادفی r ∈ {1, 2, …, R} تولید می‌کنند و بر اساس آن اجرا می‌شوند.
  • بنابراین اجراهای مختلف الگوریتم روی یک ورودی یکسان می‌تواند متفاوت باشد: یا در تعداد مراحل (یک بار سریع و یک بار کند) یا در خروجی (یک بار خوب و یک بار بد و حتی اشتباه؛ احتمال خروجی اشتباه باید خیلی کم باشد).
  • الگوریتم‌های احتمالاً درست، معروف به مونت‌کارلو (Monte Carlo): همیشه سریع‌اند ولی درستی خروجی احتمالی است. مثال: بررسی اول بودن یک عدد، بررسی درستی ضرب ماتریس، شبیه‌سازی فرایندهای فیزیکی و رندر سه‌بعدی.
  • الگوریتم‌های احتمالاً سریع، معروف به لاس‌وگاس (Las Vegas): خروجی همیشه درست است ولی سریع بودن احتمالی است. مثال: مرتب‌سازی سریع تصادفی.
  • الگوریتم‌های احتمالاً درست و احتمالاً سریع، معروف به آتلانتیک‌سیتی (Atlantic City)، زیاد مورد توجه نیستند و در مراجع کمتر مطرح می‌شوند.

تحلیل مرتب‌سازی سریع تصادفی وسواسی

  • لولا را تصادفی انتخاب می‌کنیم و تقسیم را انجام می‌دهیم. اگر اندازۀ هر دوی L و G حداقل n/4 بود ادامه می‌دهیم، وگرنه لولا را دوباره تصادفی انتخاب می‌کنیم.
  • لولا با احتمال حدود ۱/۲ خوب است (اگر بین چارک اول و سوم باشد)، پس طبق توزیع هندسی امید ریاضی تعداد تکرار انتخاب لولا ۲ است.
  • زمان اجرا: T(n) ≤ (#iterations) · Θ(n) + T(n/4) + T(3n/4) (در بدترین تقسیم قابل قبول).
  • با گرفتن امید ریاضی: E[T(n)] ≤ E[#iterations] · Θ(n) + E[T(n/4)] + E[T(3n/4)].
  • با E[#iterations] = 2 و حل رابطۀ بازگشتی (درخت بازگشت با کار Θ(n) در هر سطح و log4/3 n سطح) داریم E[T(n)] = Θ(n log n).

پیدا کردن عضو kاُم و میانه

  • ورودی: مجموعۀ S و عدد k. خروجی: عضو kاُم S از کوچک به بزرگ. میانه حالت k = ⌈n/2⌉ است.
  • با مرتب کردن در O(n log n) حل می‌شود، ولی می‌توان در زمان خطی حل کرد: مثل مرتب‌سازی سریع تقسیم می‌کنیم، ولی فقط در یکی از سه قسمت بازگشت می‌کنیم.
  • انتخاب سریع تصادفی (quickselect): لولا تصادفی است و امید ریاضی زمان اجرا Θ(n) است (با همان استدلال وسواسی: E[T(n)] ≤ 2 · Θ(n) + E[T(3n/4)]).
def select(S, k):
  x = random.choice(S)
  L = [a for a in S if a < x]
  E = [a for a in S if a == x]
  G = [a for a in S if a > x]
  if k <= len(L):
    return select(L, k)
  if k <= len(L) + len(E):
    return x
  return select(G, k - len(L) - len(E))

الگوریتم میانۀ میانه‌ها

  • الگوریتمی قطعی با زمان خطی در بدترین حالت (بلوم، فلوید، پرت، ریوست و تارجان، ۱۹۷۳):
    • الف. S را به ستون‌های ۵تایی افراز می‌کنیم (یک ستون ممکن است کمتر از ۵ عضو داشته باشد). (زمان: Θ(n))
    • ب. هر ستون ۵تایی را مرتب می‌کنیم. (زمان: Θ(n))
    • پ. میانۀ سطر وسط (میانه‌های ستون‌ها) را با همین الگوریتم پیدا می‌کنیم و آن را x می‌نامیم. (زمان: T(n/5))
    • ت. S را به سه مجموعۀ L، E و G تقسیم می‌کنیم. (زمان: Θ(n))
    • ث. بر اساس k در یکی از این سه مجموعه به صورت بازگشتی (با k جدید) به دنبال عنصر می‌گردیم. (زمان: حداکثر T(7n/10))
  • تقسیم بر اساس میانۀ سطر وسط تضمین می‌کند اندازۀ هر کدام از L و G حداکثر حدود 7n/10 است، چون حداقل نیمی از ستون‌ها هر کدام ۳ عنصر کوچک‌تر یا مساوی x دارند (و همین‌طور بزرگ‌تر یا مساوی). اگر دقیق حساب کنیم حدود ۶ تا با این مقدار فاصله دارد.
  • زمان اجرا: T(n) = T(n/5) + T(7n/10) + Θ(n) = Θ(n)، چون 1/5 + 7/10 < 1 و جمع کار سطح‌های درخت بازگشت یک سری هندسی نزولی است.
  • با وجود زمان خطی، به علت ضریب بالا در عمل از آن استفاده نمی‌شود.
def mom_select(S, k):
  if len(S) <= 5:
    return sorted(S)[k - 1]
  cols = [sorted(S[i:i + 5]) for i in range(0, len(S), 5)]
  mids = [c[len(c) // 2] for c in cols]
  x = mom_select(mids, (len(mids) + 1) // 2)
  L = [a for a in S if a < x]
  E = [a for a in S if a == x]
  G = [a for a in S if a > x]
  if k <= len(L):
    return mom_select(L, k)
  if k <= len(L) + len(E):
    return x
  return mom_select(G, k - len(L) - len(E))
