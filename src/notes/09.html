• مرور درخت دودویی جست‌وجو، خاصیت، عملیات و زمان آن‌ها (جلسۀ ۸): همه O(h).
  • اهمیت متوازن بودن درخت دودویی جست‌وجو. تعریف متوازن بودن: ارتفاع لگاریتمی، یعنی h = O(log n).
  • اولین و ساده‌ترین درخت دودویی جست‌وجوی متوازن: درخت اِی‌وی‌اِل (AVL)، توسط اَدِلسون-وِلسکی و لَندیس در سال ۱۹۶۲.

خاصیت اِی‌وی‌اِل و متوازن بودن

  • خاصیت اِی‌وی‌اِل: برای هر رأس، ارتفاع فرزند چپ و راست حداکثر یک واحد اختلاف دارد.
  • در هر رأس ارتفاع آن را نگه می‌داریم: مثالی از داده‌ساختار افزوده. رأس None را رأسی با ارتفاع ۱− درنظر می‌گیریم.
  • کجی (skew) هر رأس: ارتفاع فرزند راست منهای ارتفاع فرزند چپ. خاصیت اِی‌وی‌اِل یعنی کجی همۀ رئوس ۱−، ۰ یا ۱ است.
  • اثبات متوازن بودن درخت اِی‌وی‌اِل: به جای کمترین ارتفاع درخت nرأسی، کمترین تعداد رأس درخت با ارتفاع h را حساب می‌کنیم:
    Nh = Nh−1 + Nh−2 + 1
    • راه ساده: Nh > 2Nh−2، پس Nh ≥ 2h/2 و h ≤ 2 log2 n.
    • راه سخت ولی دقیق: با اعداد فیبوناچی Nh = Fh+3 − 1 و در نتیجه h < 1.4405 log2(n + 2).

دوران

  • دوران راست‌گرد و چپ‌گرد: ساختار درخت را عوض می‌کند ولی ترتیب میان‌ترتیب رئوس (و بنابراین خاصیت درخت دودویی جست‌وجو) را حفظ می‌کند و O(1) است.
  • در دوران چپ‌گرد روی x، فرزند راستش y جای آن را می‌گیرد، x فرزند چپ y می‌شود و زیردرخت چپ قبلی y فرزند راست x می‌شود. دوران راست‌گرد قرینۀ آن است.
  • بعد از دوران، ارتفاع و کجی دو رأس جابه‌جاشده را از پایین به بالا به‌روز می‌کنیم.
def height(node):
  return node.height if node else -1

def update(node):
  node.height = 1 + max(height(node.left), height(node.right))
  node.skew = height(node.right) - height(node.left)

def left_rotate(T, x):
  y = x.right
  x.right = y.left
  if y.left:
    y.left.parent = x
  replace(T, x, y)
  y.left = x
  x.parent = y
  update(x)
  update(y)

def right_rotate(T, x):
  y = x.left
  x.left = y.right
  if y.right:
    y.right.parent = x
  replace(T, x, y)
  y.right = x
  x.parent = y
  update(x)
  update(y)

def replace(T, x, y):
  # y takes x's place under x's parent
  y.parent = x.parent
  if x.parent is None:
    T.root = y
  elif x is x.parent.left:
    x.parent.left = y
  else:
    x.parent.right = y

درج

  • استراتژی درج: ابتدا مثل درخت دودویی جست‌وجوی ساده درج می‌کنیم، سپس از رأس درج‌شده به سمت ریشه ارتفاع‌ها را به‌روز و درخت را تصحیح می‌کنیم.
  • اگر کجی رأسی ۲ شد (ارتفاع زیردرخت راست دو واحد بیشتر است):
    • اگر کجی فرزند راست ۰ یا ۱ باشد، یک دوران چپ‌گرد روی رأس مشکل را حل می‌کند.
    • اگر کجی فرزند راست ۱− باشد (حالت زیگزاگ)، اول دوران راست‌گرد روی فرزند راست و سپس دوران چپ‌گرد روی رأس (دوران ترکیبی).
    • کجی ۲− قرینۀ همین است.
  • درج در درخت اِی‌وی‌اِل به حداکثر یک تصحیح نیاز دارد (یک دوران یا یک دوران ترکیبی): از سه حالت بالا، در دو حالتی که بعد از درج پیش می‌آیند، پس از دوران ارتفاع زیردرخت به مقدار قبل از درج برمی‌گردد و در رئوس بالاتر دیگر مشکلی نیست. حالت سوم (کجی فرزند ۰) نمی‌تواند پس از درج ایجاد شود.
  • maintain روی رأس درج‌شده (یا والد رأس حذف‌شده) صدا زده می‌شود:
def maintain(T, node):
  update(node)
  balance(T, node)
  if node.parent:
    maintain(T, node.parent)

def balance(T, node):
  if node.skew == 2:
    if node.right.skew == -1:
      right_rotate(T, node.right)
    left_rotate(T, node)
  elif node.skew == -2:
    if node.left.skew == 1:
      left_rotate(T, node.left)
    right_rotate(T, node)

def avl_insert(T, k):
  if T.root is None:
    T.root = new_node(key=k, parent=None, left=None, right=None)
    node = T.root
  else:
    node = insert(T.root, k)    # BST insert, session 8
  maintain(T, node)
  • مثالی از درج در درخت اِی‌وی‌اِل: درج ۱، ۲، ۳ به ترتیب یک دوران چپ‌گرد روی ۱ و سپس درج ۵ و ۴ یک دوران ترکیبی روی ۳ ایجاد می‌کند.

حذف

  • حذف در درخت اِی‌وی‌اِل مشابه درج است: حذف مثل درخت دودویی جست‌وجو و سپس maintain از والد رأسی که واقعاً حذف شده است. تفاوت این است که ممکن است در چند سطح نیاز به دوران باشد: تا Θ(log n) دوران.
def avl_delete(T, node):
  if node.left and node.right:
    succ = find_min(node.right)
    node.key = succ.key
    node = succ
  parent = node.parent
  delete(T, node)    # node has at most one child now
  if parent:
    maintain(T, parent)

مرتب‌سازی اِی‌وی‌اِل

  • n درج هر کدام در O(log n) و یک پیمایش میان‌ترتیب در O(n): در مجموع O(n log n).
def avl_sort(A):
  T = new_tree()
  for a in A:
    avl_insert(T, a)
  out = []
  in_order(T.root, out)
  return out
