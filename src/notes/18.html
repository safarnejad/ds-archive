مسئلۀ تطابق رشته‌ها

  • نسخه‌ای از مسئله که در جلسۀ ۱۵ بررسی شد: یک رشتۀ (بزرگ) t و یک رشتۀ (کوچک) s داریم و می‌خواهیم s را به عنوان زیررشته‌ای از t پیدا کنیم.
  • الگوریتم‌های مختلفی مثل KMP، بویر-مور و رابین-کارپ برای این مسئله پیشنهاد شده‌اند. الگوریتم رابین-کارپ در جلسۀ ۱۵ توضیح داده شد.
  • در این جلسه به نسخه‌ای از همین سؤال می‌پردازیم که رشتۀ t از ابتدا داده شده است (و می‌توانیم آن را پیش‌پردازش کنیم) و باید به تعدادی پرسش (query) پاسخ دهیم که هر کدام s خود را دارد.

مسئلۀ رشتۀ قبلی

  • رشته‌های T1, T2, …, Tk داده شده‌اند. پس از پیش‌پردازش، در هر پرسش یک رشتۀ s داده می‌شود و می‌خواهیم جای s را در لغت‌نامۀ مرتب این رشته‌ها پیدا کنیم. در واقع خروجی، رشتۀ قبل از s در میان T1, …, Tk است.
  • به ترتیب رشته‌ها در لغت‌نامه ترتیب لغت‌نامه‌ای (lexicographic) می‌گوییم.
  • این مسئله با جست‌وجوی دودویی حل می‌شود، اما هر مقایسه ممکن است به اندازۀ طول s طول بکشد و اگر s طولانی باشد زمان‌بر است.
  • یک راه، استفاده از درهم‌سازی مشابه درهم‌سازی غلتان جلسۀ ۱۵ است: درهم‌سازی همۀ پیشوندهای T1, …, Tk را در پیش‌پردازش و درهم‌سازی همۀ پیشوندهای s را در هر پرسش حساب می‌کنیم. با جست‌وجوی دودویی روی طول طولانی‌ترین پیشوند مشترک، هر مقایسه در O(log |s|) انجام می‌شود و زمان هر پرسش O(log |s| · log k) است (به علاوۀ O(|s|) برای درهم‌سازی پیشوندهای s).

ترای و ترای فشرده

  • یک داده‌ساختار درختی جدید که برای مسائل بالا مفید است. نام ترای (trie) از واژۀ retrieval به معنی بازیابی (اطلاعات) آمده است.
  • ترای درختی است که هر یال آن به یک حرف از الفبا (Σ) مربوط است. به جای این که کلیدها در رأس‌ها ذخیره شوند، کلید هر رأس همان حروف روی مسیر ریشه تا آن رأس است.
  • مثال: ترای رشته‌های ana$، ann$، anna$ و anne$. حرف $ که عضو Σ نیست پایان رشته را نشان می‌دهد تا هیچ رشته‌ای پیشوند رشتۀ دیگر نباشد و هر رشته به یک برگ برسد.
  • عملیات ترای: درج یک رشته، حذف یک رشته، جست‌وجوی یک رشته و نوشتن همۀ رشته‌ها (به ترتیب لغت‌نامه‌ای). سه عمل اول O(|s|) طول می‌کشند (با فرض این‌که پیدا کردن فرزند هر رأس O(1) باشد).
  • در کد زیر به جای $ در هر رأس node.end را نگه می‌داریم و node.count تعداد رشته‌های زیردرخت است که با آن تعداد رشته‌های دارای یک پیشوند داده شده را هم جواب می‌دهیم. فرزندان در دیکشنری (جدول درهم‌سازی) ذخیره می‌شوند.
class TrieNode:
  def __init__(self):
    self.children = {}
    self.end = False
    self.count = 0

def insert(root, s):
  if search(root, s):
    return
  node = root
  node.count += 1
  for c in s:
    if c not in node.children:
      node.children[c] = TrieNode()
    node = node.children[c]
    node.count += 1
  node.end = True

def find(root, s):
  node = root
  for c in s:
    if c not in node.children:
      return None
    node = node.children[c]
  return node

def search(root, s):
  node = find(root, s)
  return node is not None and node.end

def count_prefix(root, p):
  node = find(root, p)
  return node.count if node else 0

def delete(root, s):
  if not search(root, s):
    return
  node = root
  node.count -= 1
  for c in s:
    child = node.children[c]
    child.count -= 1
    if child.count == 0:
      del node.children[c]
      return
    node = child
  node.end = False

def words(node, prefix=''):
  if node.end:
    yield prefix
  for c in sorted(node.children):
    yield from words(node.children[c], prefix + c)
  • در ترای فشرده (compressed یا compact) رأس‌هایی که فقط یک فرزند دارند حذف می‌شوند و روی هر یال یک رشته (به جای یک حرف) قرار می‌گیرد. تعداد رأس‌های ترای فشردۀ k رشته O(k) است.

حل مسئلۀ رشتۀ قبلی با ترای

  • ابتدا از رشته‌های T1, …, Tk یک ترای می‌سازیم. برای پاسخ به هر پرسش، s را می‌خوانیم و هم‌زمان از ریشۀ ترای مطابق حرفی که می‌خوانیم پایین می‌رویم.
  • اگر در رأس v باشیم و v فرزندی برای حرف خواندۀ c نداشته باشد، جواب بزرگ‌ترین رشته در زیردرخت فرزندانی از v است که حرفشان قبل از c است (و اگر چنین فرزندی نبود، جواب در بالاتر از v است).
  • در کد زیر برای هر رأس که از آن رد می‌شویم، بزرگ‌ترین رشتۀ کوچک‌تر از مسیر فعلی را به‌روز می‌کنیم. خروجی بزرگ‌ترین رشتۀ ذخیره‌شده‌ای است که از s بزرگ‌تر نیست (یا None).
def largest(node, prefix):
  while node.children:
    c = max(node.children)
    node, prefix = node.children[c], prefix + c
  return prefix

def predecessor(root, s):
  best, node, prefix = None, root, ''
  for c in s:
    if node.end:
      best = prefix
    smaller = [d for d in node.children if d < c]
    if smaller:
      d = max(smaller)
      best = largest(node.children[d], prefix + d)
    if c not in node.children:
      return best
    node, prefix = node.children[c], prefix + c
  if node.end:
    return prefix
  return best
  • زمان و حافظۀ این الگوریتم به داده‌ساختار هر رأس ترای بستگی دارد. |T| را تعداد رأس‌های ترای می‌گیریم:
    • ۱. آرایه: برای هر رأس آرایه‌ای به طول |Σ| که هر خانۀ آن به فرزند مربوط اشاره می‌کند یا None است. پیدا کردن یک رشته O(|s|) و پرسش رشتۀ قبلی O(|s| + |Σ|) طول می‌کشد. جملۀ O(|Σ|) مربوط به وقتی است که فرزند حرف خوانده‌شده وجود ندارد و باید آخرین حرف قبل از آن را پیدا کنیم. حافظه O(|T| · |Σ|) است که زیاد است.
    • ۲. لیست مرتب (یا درخت دودویی جست‌وجو): به جای آرایه‌ای که احتمالاً خانه‌های خالی زیادی دارد. حافظه به O(|T|) کم می‌شود (تمرین: چرا؟) ولی زمان هر پرسش به O(|s| log |Σ|) می‌رسد.
    • ۳. جدول درهم‌سازی: حافظه O(|T|)، پیدا کردن یک رشته O(|s|) و پرسش رشتۀ قبلی O(|s| + |Σ|) (مثل کد بالا). اگر Σ بزرگ باشد این زمان زیاد است.
    • ۴. درخت فان امده بوآس (van Emde Boas) که در این درس پوشش داده نمی‌شود: حافظه O(|T|) و زمان پرسش O(|s| log log |Σ|).
    • ۵. درخت دودویی جست‌وجوی وزن‌دار متوازن: حافظه O(|T|) و زمان پرسش O(|s| + log k). با کمی تلاش می‌توان آن را به O(|s| + log |Σ|) رساند.
      • فرزندان هر رأس را در یک درخت دودویی وزن‌دار نگه می‌داریم که وزن هر فرزند تعداد برگ‌های زیردرخت آن است. این درخت دودویی بر حسب این وزن‌ها تا حد امکان متوازن است.
      • لم: زمان پاسخ به پرسش در این ساختار O(|s| + log k) است. ایدۀ اثبات: در هر قدم یا یک حرف روی s جلو می‌رویم یا دست کم یک‌سوم برگ‌ها را کنار می‌گذاریم.

درخت پسوندی

  • درخت پسوندی (suffix tree) ترای فشرده‌ای است که شامل همۀ پسوندهای یک رشته است.
  • حرف $ را که عضو Σ نیست به انتهای رشته اضافه می‌کنیم و فرض می‌کنیم $ از همۀ حروف دیگر کوچک‌تر است. مثال: درخت پسوندی banana$.
  • برای جلوگیری از زیاد شدن حافظه، به جای ذخیرۀ رشته روی یال‌های ترای فشرده، اندیس شروع و پایان آن را در رشتۀ اصلی نگه می‌داریم (اگر این اندیس‌ها یکتا نباشند از هر کدام می‌توان استفاده کرد). در این صورت حافظه O(|t|) است.
  • درخت پسوندی را می‌توان در زمان خطی ساخت. کد زیر نسخۀ ساده و غیرفشرده (ترای پسوندی) است که همۀ پسوندها را یکی‌یکی در ترای درج می‌کند و زمان و حافظۀ آن O(|t|2) است. هر برگ اندیس شروع پسوند خود را دارد.
def suffix_trie(t):
  t += '$'
  root = {}
  for i in range(len(t)):
    node = root
    for c in t[i:]:
      node = node.setdefault(c, {})
    node['start'] = i
  return root

def leaves(node):
  for c in node:
    if c == 'start':
      yield node[c]
    else:
      yield from leaves(node[c])

def occurrences(root, s):
  node = root
  for c in s:
    if c not in node:
      return []
    node = node[c]
  return sorted(leaves(node))

کاربردهای درخت پسوندی

  • ۱. تطابق رشته‌ها (مسئلۀ ابتدای جلسه) در زمان O(|s|) برای هر پرسش.
  • ۲. تطابق رشته‌ها با شمردن تعداد تکرارها یا خروجی دادن همۀ مکان‌های وقوع: برگ‌های زیردرختی که به آن می‌رسیم (تابع occurrences بالا).
  • ۳. پیدا کردن طولانی‌ترین زیررشتۀ تکراری یک رشته: عمیق‌ترین (از نظر تعداد حروف) رأس داخلی.
  • ۴. طولانی‌ترین زیررشتۀ مشترک k رشته در زمان خطی: رشته‌ها را به صورت T1$1T2$2…Tk$k به هم می‌چسبانیم و درخت پسوندی آن را می‌سازیم. سپس با پیمایش درخت طولانی‌ترین رشته‌ای را پیدا می‌کنیم که در زیردرخت آن همۀ $ها ظاهر شوند.
  • جالب است که مسئلۀ مشابه، یعنی طولانی‌ترین زیردنبالۀ مشترک (که لازم نیست پیوسته باشد) برای k رشته، الگوریتم کارایی ندارد (برای k دلخواه NP-سخت است).
  • آرایۀ پسوندی که معادل درخت پسوندی و ساده‌تر از آن است، موضوع جلسۀ ۱۹ است.
