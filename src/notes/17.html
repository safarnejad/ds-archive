• اعداد بزرگ (مثلاً با یک میلیون رقم) داده‌ساختار خاص خود را لازم دارند. در پایتون int (در پایتون ۲ long) و در جاوا BigInteger داده‌ساختارهای خاصی برای اعداد بزرگ‌اند.
  • در عمل اگر اعداد را در مبنای 215 یا 104 ذخیره کنیم، الگوریتم‌ها سریع‌تر از حالتی اجرا می‌شوند که اعداد در مبنای ۲ یا ۱۰ ذخیره شده باشند، چون از توان CPU بیشتر استفاده می‌کنیم.
    • این بهبود در ضریب زمان اجراست و نه در تحلیل مجانبی.
    • مبنا باید طوری انتخاب شود که حاصل‌ضرب دو رقم آن در یک کلمه (در عمل int) جا شود.

الگوریتم‌های ضرب دو عدد d رقمی

  • ۱. الگوریتم مدرسه: Θ(d2).
  • ۲. الگوریتم کاراتسوبا: Θ(dlog2 3) = Θ(d1.585). پایتون از این روش استفاده می‌کند.
  • ۳. الگوریتم تام-کوک (Toom-Cook): Θ(dlog3 5) = Θ(d1.465). مشابه کاراتسوباست و در بستۀ gmpy پایتون موجود است.
  • ۴. الگوریتم شونهاگه-اشتراسن (Schönhage-Strassen): Θ(d log d log log d). زمان تقریباً خطی با استفاده از تبدیل فوریۀ سریع (FFT). آن هم در gmpy موجود است.
  • ۵. الگوریتم فورر (Fürer، ۲۰۰۷): d log d · 2O(log* d). log* d تعداد دفعاتی است که باید از d لگاریتم بگیریم تا به عددی کمتر یا مساوی ۱ برسیم.
  • در سال ۲۰۱۹ هاروی و فان در هوفن (Harvey, van der Hoeven) الگوریتمی با زمان O(d log d) ارائه کردند.

الگوریتم کاراتسوبا

  • ورودی: دو عدد a و b در مبنای r که حداکثر d رقم دارند.
  • فرض می‌کنیم a = a1rd/2 + a0 و b = b1rd/2 + b0. داریم
    ab = a1b1 rd + (a0b1 + a1b0) rd/2 + a0b0 = c2 rd + c1 rd/2 + c0
  • دو ضریب c0 = a0b0 و c2 = a1b1 به راحتی (به صورت بازگشتی) به دست می‌آیند. برای ضریب سوم توجه کنید که c1 = (a0 + a1)(b0 + b1) − c0 − c2.
  • پس به جای چهار ضرب به سه ضرب با طول d/2 و تعدادی جمع با طول حداکثر d نیاز داریم:
    T(d) = 3T(d/2) + Θ(d) = Θ(dlog2 3) = Θ(d1.5849…)
  • در کد زیر مبنا r = 2 است و نصف کردن عدد با شیفت بیتی انجام می‌شود. اعداد کوچک را مستقیم ضرب می‌کنیم.
def karatsuba(a, b):
  if a < 2**64 or b < 2**64:
    return a * b
  h = max(a.bit_length(), b.bit_length()) // 2
  a1, a0 = a >> h, a & ((1 << h) - 1)
  b1, b0 = b >> h, b & ((1 << h) - 1)
  c2 = karatsuba(a1, b1)
  c0 = karatsuba(a0, b0)
  c1 = karatsuba(a0 + a1, b0 + b1) - c0 - c2
  return (c2 << (2 * h)) + (c1 << h) + c0

تقسیم اعداد بزرگ

  • ۱. روش مدرسه: Θ(d2).
  • ۲. جست‌وجوی دودویی روی خارج‌قسمت و ضرب: log2(rd) · T(d) = Θ(d) · T(d) که T(d) زمان ضرب است.
  • ۳. روش نیوتون: Θ(T(d)). نیاز به طراحی و تحلیل دقیق دارد، زیرا (۱) خود روش نیوتون به تقسیم نیاز دارد و (۲) با این که در هر مرحله ضرب انجام می‌دهیم، باید کاری کنیم که مرتبۀ زمان کل مراحل از یک ضرب بیشتر نشود.

روش نیوتون

  • به دنبال ریشۀ معادلۀ f(x) = 0 هستیم. در هر مرحله یک نقطۀ xi داریم و می‌خواهیم نقطۀ بهتری به دست آوریم.
  • روش نیوتون با استفاده از شیب نمودار (خط مماس) نقطۀ بعدی را این‌طور پیشنهاد می‌کند:
    xi+1 = xi − f(xi) / f ′(xi)
  • وقتی f تابع خوبی باشد، این روش از جست‌وجوی دودویی بسیار هوشمندانه‌تر است.

تقسیم با روش نیوتون

  • برای محاسبۀ a/b کافی است 1/b را حساب کنیم و آن را در a ضرب کنیم.
  • به جای عدد اعشاری 1/b می‌توانیم عدد صحیح ⌊R/b⌋ را حساب کنیم که R = rk است.
  • تابع مورد استفاده f(x) = 1/x − b/R و مشتق آن f ′(x) = −1/x2 است. هر مرحله:
    xi+1 = xi − f(xi) / f ′(xi) = 2xi − b xi2 / R
  • در هر مرحله فقط به ضرب و تقسیم بر R نیاز داریم. تقسیم بر R ساده است و با حذف k رقم آخر انجام می‌شود.
  • تحلیل: فرض کنید xi = (R/b)(1 + εi). با محاسبۀ xi+1 داریم εi+1 = −εi2. بنابراین (با برخی فرض‌ها) تعداد ارقام بامعنی در هر مرحله دو برابر می‌شود و با تحلیل ساده زمان اجرا Θ(log d) · T(d) است.
  • حذف ضریب Θ(log d): چون در هر مرحله تعداد ارقام بامعنی مشخص است، لازم نیست محاسبات آن مرحله را با d رقم انجام دهیم و همان تعداد رقم کافی است. در این صورت زمان اجرا
    C · T(1) + C · T(2) + C · T(4) + … + C · T(d) = Θ(T(d))
    است که C یک عدد ثابت است. پس تقسیم از نظر مجانبی در زمان ضرب انجام می‌شود.
  • در کد زیر R = 2k است و تقسیم بر آن یک شیفت است. حدس اولیه از R/b کمتر است و چون 1 − ε2 ≤ 1، دنبالۀ تقریب‌ها از پایین بالا می‌رود. خطای گرد کردن را در آخر با چند جمع و تفریق اصلاح می‌کنیم. (برای سادگی همۀ مراحل با دقت کامل انجام می‌شوند.)
def reciprocal(b, k):  # floor(2**k / b)
  x = 1 << max(k - b.bit_length(), 0)
  while True:
    y = 2 * x - ((b * x * x) >> k)
    if y <= x:
      break
    x = y
  while (x + 1) * b <= 1 << k:
    x += 1
  while x * b > 1 << k:
    x -= 1
  return x

def divide(a, b):
  k = a.bit_length() + 1
  q = (a * reciprocal(b, k)) >> k
  while (q + 1) * b <= a:
    q += 1
  return q

جذر با روش نیوتون

  • هدف: محاسبۀ √a. تابع مورد استفاده f(x) = x2 − a و مشتق آن f ′(x) = 2x است. هر مرحله:
    xi+1 = xi − (xi2 − a) / 2xi = (xi + a/xi) / 2
  • برای تحلیل خطا فرض کنید xi = √a (1 + εi). با محاسبۀ xi+1 داریم εi+1 = εi2 / 2(1 + εi).
  • بنابراین این‌جا هم تعداد ارقام بامعنی در هر مرحله دو برابر می‌شود و مشابه تحلیل تقسیم، زمان جذر (از نظر مجانبی) برابر زمان ضرب است.
  • جذر صحیح ⌊√a⌋: از عددی بزرگ‌تر از جواب شروع می‌کنیم. چون εi+1 ≥ 0، تقریب‌ها از بالا پایین می‌آیند و وقتی دیگر کم نشدند به جواب رسیده‌ایم.
def isqrt(a):
  if a == 0:
    return 0
  x = 1 << ((a.bit_length() + 1) // 2)
  while True:
    y = (x + a // x) // 2
    if y >= x:
      return x
    x = y
