جلسۀ سوم: حل روابط بازگشتی

مطالعۀ بیشتر: ۳-۴ تا ۳-۶ از قدسی و ۴.۳ تا ۴.۶ از CLRS

فهرست این جلسه
  • حدس و استقرا
  • تکرار با جای‌گذاری و درخت بازگشت
  • قضیۀ اصلی
  • روابط بازگشتی خطی همگن
  • زمان اجرای الگوریتم‌های بازگشتی (مثل تقسیم و حل در جلسۀ بعد) به صورت یک رابطۀ بازگشتی بیان می‌شود. مثلاً برای مرتب‌سازی ادغامی T(n) = 2T(n/2) + Θ(n).
  • روش‌های حل رابطۀ بازگشتی:
    • حدس و استقرا
    • تکرار با جای‌گذاری (باز کردن رابطه) و درخت بازگشت
    • قضیۀ اصلی
    • حل روابط بازگشتی خطی همگن و ناهمگن
    • روش‌های دیگر مانند تابع مولد

حدس و استقرا

  • جواب را حدس می‌زنیم و با استقرا ثابت می‌کنیم. ثابت‌ها را در حدس نگه می‌داریم تا در استقرا مشخص شوند.
  • مثال: برای T(n) = 2T(⌊n/2⌋) + n حدس می‌زنیم T(n) ≤ c n log n. داریم T(n) ≤ 2c(n/2) log(n/2) + n = c n log n − c n + n ≤ c n log n به ازای c ≥ 1.
  • دام رایج: اثبات T(n) ≤ c n برای همین رابطه با نوشتن T(n) ≤ c n + n = O(n) غلط است، چون باید دقیقاً همان صورت حدس، یعنی c n، به دست بیاید.

تکرار با جای‌گذاری و درخت بازگشت

  • رابطه را چند بار باز می‌کنیم تا الگو پیدا شود و سپس جمع را حساب می‌کنیم.
  • مثال برج هانوی: T(n) = 2T(n − 1) + 1 = 4T(n − 2) + 2 + 1 = … = 2n − 1.
  • درخت بازگشت برای T(n) = 2T(n/2) + cn: در هر سطح جمع کارها cn است و log2 n سطح داریم، پس T(n) = Θ(n log n).
def hanoi(n, src, dst, tmp):
  if n > 0:
    hanoi(n - 1, src, tmp, dst)
    print(src, '->', dst)
    hanoi(n - 1, tmp, dst, src)

قضیۀ اصلی

  • برای T(n) = a T(n/b) + f(n): تعداد زیرمسئله‌ها a، اندازۀ هر کدام n/b و مجموع زمان تقسیم و ادغام f(n) است.
  • تعداد برگ‌های درخت بازگشت L = nlogb a و ارتفاع آن logb n است.
  • ۱. اگر f(n) = O(L1−ε) برای یک ε > 0، آنگاه T(n) = Θ(L). برگ‌ها غالب‌اند.
  • ۲. اگر f(n) = Θ(L logk n) برای k ≥ 0، آنگاه T(n) = Θ(L logk+1 n). همۀ سطح‌ها تقریباً برابرند.
  • ۳. اگر f(n) = Ω(L1+ε) برای یک ε > 0 و a f(n/b) ≤ c f(n) برای یک c < 1، آنگاه T(n) = Θ(f(n)). ریشه غالب است.
  • مثال‌ها: جست‌وجوی دودویی T(n) = T(n/2) + 1 = Θ(log n) (حالت ۲)، ضرب کاراتسوبا T(n) = 3T(n/2) + n = Θ(nlog2 3) (حالت ۱) و T(n) = 2T(n/2) + n2 = Θ(n2) (حالت ۳).

روابط بازگشتی خطی همگن

  • اگر ciها اعداد حقیقی باشند، an = c1an−1 + c2an−2 + … + ckan−k یک رابطۀ بازگشتی خطی همگن از درجۀ k است.
  • معادلۀ مشخصه: rk = c1rk−1 + … + ck. اگر ریشه‌های r1, …, rk متمایز باشند، an = α1r1n + … + αkrkn و ضریب‌ها از شرایط اولیه به دست می‌آیند. برای ریشۀ تکراری r با تکرار m، جمله‌های rn, n rn, …, nm−1rn را داریم.
  • مثال فیبوناچی: Fn = Fn−1 + Fn−2، معادلۀ مشخصه r2 = r + 1 و ریشه‌ها φ = (1 + √5)/2 و (1 − √5)/2، پس Fn = (φn − (1 − φ)n)/√5 = Θ(φn).
