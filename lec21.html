داده‌ساختارهای افزودۀ معمول

  • هدف: در هر رأس v یک درخت، مقدار تابع f(v) را روی زیردرخت v نگه داریم.
  • شرط: مقدار تابع برای v باید از روی مقدار تابع فرزندان v (و خود v) در O(1) محاسبه شود.
  • با این خاصیت، هر تغییر در داده‌ساختار (درج، حذف یا تغییر مقدار یک عنصر) فقط روی مقدار تابع رأس‌های مسیر آن رأس تا ریشه اثر می‌گذارد و به‌روزرسانی این مقادیر Θ(h) طول می‌کشد که h ارتفاع درخت است. در دوران‌ها هم فقط مقدار چند رأس عوض می‌شود.
  • درخت‌های اِی‌وی‌اِل (جلسۀ ۹) برای این کار مناسب‌اند، چون ارتفاعشان O(log n) است.
  • توابع معمول: جمع، ضرب، کمینه، بیشینه، xor و …

درخت مرتبه آماری

  • واسط درخت مرتبه آماری (order-statistic tree): درج، حذف، عنصر بعدی، مرتبۀ یک عنصر داده شده (rank) و انتخاب عنصر با مرتبۀ داده شده (select).
  • ایده: در هر رأس درخت اِی‌وی‌اِل تعداد عناصر زیردرخت آن (node.size) را نگه می‌داریم. داریم node.size = size(node.left) + size(node.right) + 1.
  • به‌روزرسانی و جست‌وجو در زمان Θ(log n) انجام می‌شوند.
  • select(node, k): اگر k برابر اندازۀ زیردرخت چپ به علاوۀ یک باشد، جواب خود رأس است؛ اگر کمتر باشد در زیردرخت چپ و اگر بیشتر باشد در زیردرخت راست به دنبال عنصر (k − size(left) − 1)اُم می‌گردیم. مرتبه‌ها از ۱ شروع می‌شوند.
  • rank(node): از رأس تا ریشه بالا می‌رویم و هر بار که از فرزند راست به پدر می‌رسیم، اندازۀ زیردرخت چپ پدر و خود پدر را اضافه می‌کنیم.
def size(node):
  return node.size if node else 0

def update_size(node):
  node.size = size(node.left) + size(node.right) + 1

def select(node, k):
  r = size(node.left) + 1
  if k == r:
    return node
  if k < r:
    return select(node.left, k)
  return select(node.right, k - r)

def rank(node):
  r = size(node.left) + 1
  while node.parent:
    if node == node.parent.right:
      r += size(node.parent.left) + 1
    node = node.parent
  return r
  • update_size باید بعد از هر تغییر، برای رأس‌های مسیر تا ریشه و رأس‌های درگیر در دوران‌ها (از پایین به بالا) صدا زده شود، همان جایی که ارتفاع رأس‌ها در درخت اِی‌وی‌اِل به‌روز می‌شود.
  • مثال: در درختی با کلیدهای ۱ تا ۷ که ریشۀ آن ۴ است، select(root, 6) به زیردرخت راست (ریشۀ ۶) با k = 2 می‌رود و ۶ را برمی‌گرداند.

درخت پاره‌خطی

  • با فرض این که کلیدها اعداد صحیح ۱ تا m (یا اندیس‌های یک آرایه) باشند، یک درخت دودویی تقریباً کامل روی آن‌ها می‌سازیم که هر رأس آن متناظر یک بازه است و مثل قبل تابع f را برای هر رأس و زیردرخت آن نگه می‌داریم (درخت پاره‌خطی یا segment tree).
  • در مقایسه با درخت اِی‌وی‌اِل افزوده، ساختار درخت پاره‌خطی تغییر نمی‌کند (دوران ندارد) و پیاده‌سازی آن آسان‌تر است.
  • حافظۀ آن Θ(m) و زمان هر عمل Θ(log m) است (و نه Θ(log n) که n تعداد عناصر موجود است).
  • در کد زیر درخت در آرایۀ T ذخیره شده، رأس v متناظر بازۀ [lo, hi] است و فرزندانش 2v و 2v + 1‌اند (مثل هرم). تابع، جمع است. برای کمینه (جلسۀ ۲۰) کافی است + را با min عوض کنیم.
def build(T, A, v, lo, hi):
  if lo == hi:
    T[v] = A[lo]
    return
  mid = (lo + hi) // 2
  build(T, A, 2 * v, lo, mid)
  build(T, A, 2 * v + 1, mid + 1, hi)
  T[v] = T[2 * v] + T[2 * v + 1]

def query(T, v, lo, hi, i, j):  # sum of A[i..j]
  if j < lo or hi < i:
    return 0
  if i <= lo and hi <= j:
    return T[v]
  mid = (lo + hi) // 2
  return query(T, 2 * v, lo, mid, i, j) + query(T, 2 * v + 1, mid + 1, hi, i, j)

def update(T, v, lo, hi, i, x):  # A[i] = x
  if lo == hi:
    T[v] = x
    return
  mid = (lo + hi) // 2
  if i <= mid:
    update(T, 2 * v, lo, mid, i, x)
  else:
    update(T, 2 * v + 1, mid + 1, hi, i, x)
  T[v] = T[2 * v] + T[2 * v + 1]

# T = [0] * (4 * len(A)); build(T, A, 1, 0, len(A) - 1)

انتشار با تأخیر

  • وقتی به جای یک عنصر بخواهیم همۀ عناصر یک بازه را تغییر دهیم، مثلاً همه را برابر یک مقدار کنیم یا به همه یک مقدار اضافه کنیم، برای این که زمان زیاد نشود از انتشار با تأخیر (lazy propagation) استفاده می‌کنیم. این روش هم در درخت اِی‌وی‌اِل افزوده و هم در درخت پاره‌خطی قابل استفاده است.
  • ایده: تا وقتی به یک رأس نرفته‌ایم، به مقدار تابع آن نیاز نداریم. روی رأس یک علامت (flag) می‌گذاریم که یعنی عناصر این زیردرخت به‌روز نیستند و چه تغییری باید رویشان اعمال شود.
  • در زمان جست‌وجو یا به‌روزرسانی، اگر از چنین رأسی پایین رفتیم، فرزندانش را به‌روز می‌کنیم و علامت را به آن‌ها منتقل می‌کنیم.
  • هر به‌روزرسانی یا پرسش در هر سطح حداکثر به ۴ رأس و در کل به حداکثر 4 log2 n رأس دسترسی دارد. پس زمان به‌روزرسانی یک بازه و پرسش هر دو (از نظر مجانبی) مثل قبل است.
  • در کد زیر به همۀ عناصر یک بازه عددی اضافه می‌شود و add[v] مقداری است که هنوز به فرزندان v منتقل نشده است.
def push(T, add, v, lo, mid, hi):
  if add[v]:
    for c, length in ((2 * v, mid - lo + 1), (2 * v + 1, hi - mid)):
      T[c] += add[v] * length
      add[c] += add[v]
    add[v] = 0

def range_add(T, add, v, lo, hi, i, j, x):
  if j < lo or hi < i:
    return
  if i <= lo and hi <= j:
    T[v] += x * (hi - lo + 1)
    add[v] += x
    return
  mid = (lo + hi) // 2
  push(T, add, v, lo, mid, hi)
  range_add(T, add, 2 * v, lo, mid, i, j, x)
  range_add(T, add, 2 * v + 1, mid + 1, hi, i, j, x)
  T[v] = T[2 * v] + T[2 * v + 1]

def range_sum(T, add, v, lo, hi, i, j):
  if j < lo or hi < i:
    return 0
  if i <= lo and hi <= j:
    return T[v]
  mid = (lo + hi) // 2
  push(T, add, v, lo, mid, hi)
  return range_sum(T, add, 2 * v, lo, mid, i, j) + range_sum(T, add, 2 * v + 1, mid + 1, hi, i, j)

درخت فنویک

  • اگر در درخت پاره‌خطی جمع را نگه داریم، کافی است مقدار تابع را فقط برای نصف رأس‌ها ذخیره کنیم (مثلاً فقط فرزندان چپ، چون مقدار فرزند راست از تفاضل پدر و فرزند چپ به دست می‌آید) و به جای 2n − 1 رأس، اطلاعات را در n خانه نگه داریم.
  • درخت فنویک (Fenwick tree یا binary indexed tree) این کار را هوشمندانه انجام می‌دهد و جمع‌ها را در آرایه‌ای هم‌اندازۀ خود داده‌ها، بدون هیچ حافظۀ اضافه‌ای، نگه می‌دارد.
  • خانۀ i جمع A[i − lowbit(i) + 1 … i] را دارد که lowbit(i) = i & -i کم‌ارزش‌ترین بیت یک عدد i است. هر دو عمل O(log n) طول می‌کشند.
  • عملیاتی مثل جمع و xor (و ضرب اعداد ناصفر) پشتیبانی می‌شوند، چون جواب یک بازه از تفاضل دو پیشوند به دست می‌آید. کمینه و بیشینه پشتیبانی نمی‌شوند، چون وارون ندارند.
  • تصویر ساختار درختی آن پیچیده است ولی کد بسیار کوتاهی دارد. اندیس‌گذاری آرایه از ۱ است (F[0] استفاده نمی‌شود و F در ابتدا [0] * (n + 1) است).
def prefix_sum(F, i):  # A[1] + ... + A[i]
  result = 0
  while i > 0:
    result += F[i]
    i -= i & -i
  return result

def add(F, i, x):  # A[i] += x
  while i < len(F):
    F[i] += x
    i += i & -i
  • مثال روی درخت فنویک ۱۴ خانه‌ای: prefix_sum(F, 13) خانه‌های ۱۳، ۱۲ و ۸ را جمع می‌کند (13 = 11012) و add(F, 5, 2) خانه‌های ۵، ۶ و ۸ را تغییر می‌دهد (خانۀ ۱۶ وجود ندارد).
