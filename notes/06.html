جلسۀ ۶: درخت‌ها، پیمایش درخت و درخت عبارت

مطالعۀ بیشتر: ۴-۴ از قدسی و ۱۰.۴ از CLRS

تعریف‌های درخت

  • به یک گراف همبند و بدون دور درخت می‌گوییم. درخت با n رأس n − 1 یال دارد.
  • درخت بدون ریشه یا ریشه‌دار. اگر یال‌ها را طوری جهت دهیم که درجۀ ورودی هر رأس حداکثر ۱ باشد، یک رابطۀ پدر-فرزندی بین رئوس به دست می‌آید: هر رأس به جز ریشه دقیقاً یک پدر دارد.
  • تعریف بازگشتی: یک رأس به تنهایی یک درخت است. از k درخت مستقل با ریشه‌های r1, …, rk درخت بزرگ‌تری با ریشۀ r می‌سازیم که r1, …, rk فرزندان آن باشند. آن k درخت زیردرخت‌های درخت بزرگ‌تر هستند.
  • واژه‌ها:
    • ریشه (root): رأسی که پدر ندارد. برگ (leaf): رأس بدون فرزند. رأس داخلی: رأس غیر برگ. برادرها: رئوسی که یک پدر دارند.
    • زیردرخت رأس b: درختی به ریشۀ b شامل b و همۀ فرزندان و نوادگان آن.
    • اولاد رأس v: همۀ رئوس زیردرخت v. اجداد v: همۀ رئوس مسیر ریشه تا v. اولاد و اجداد واقعی: همین‌ها به جز خود v.
    • عمق (سطح) یک رأس: طول مسیر ریشه تا آن رأس. ارتفاع رأس v: طول بلندترین مسیر از v به برگ‌های زیردرختش. ارتفاع درخت: ارتفاع ریشه.
    • جنگل: تعدادی درخت.
  • درخت مرتب و نامرتب: در درخت مرتب ترتیب فرزندان مهم است. درخت برچسب‌دار: روی هر رأس یک برچسب (کلید) قرار دارد.
  • درخت kتایی: هر رأس حداکثر k فرزند دارد. درخت دودویی: درخت مرتبی که هر رأس آن حداکثر دو فرزند (چپ و راست) دارد.
  • مثال‌هایی از کاربرد درخت: ساختار پوشه‌ها (directory)، فایل‌های XML و JSON، یکی از ساختارهای پیشنهادی برای تبدیل RNA به DNA.

درخت دودویی تقریباً کامل

  • درخت دودویی کامل: همۀ سطرها پرند. درخت دودویی تقریباً کامل: همۀ سطرها به جز سطر آخر پرند و برگ‌های سطر آخر از چپ به راست چیده شده‌اند.
  • این درخت را می‌توان بدون حافظۀ اضافه (بدون اشاره‌گر) در آرایه ذخیره کرد: رئوس را سطر به سطر و از چپ به راست در خانه‌های 0, 1, …, n − 1 می‌گذاریم و
    parent(i) = ⌊(i − 1)/2⌋ left(i) = 2i + 1 right(i) = 2i + 2
  • ارتفاع درخت تقریباً کامل با n رأس ⌊log2 n⌋ است. این نمایش در جلسۀ ۷ برای هرم استفاده می‌شود.

ذخیرۀ درخت‌های دیگر

  • با آرایۀ پدر: برای هر رأس پدرش را ذخیره می‌کنیم و برای ریشه مقدار خاصی (مثلاً None) می‌گذاریم.
  • با اشاره‌گر: هر رأس یک شیء با کلید و اشاره‌گرهایی مثل node.parent، node.left و node.right است.
  • برای درخت با تعداد فرزندان دلخواه: برای هر رأس سه اشاره‌گر پدر (parent)، چپ‌ترین فرزند (left_child) و برادر سمت راست (right_sibling) نگه می‌داریم.

پیمایش درخت

  • فرض کنید درخت T ریشۀ r و زیردرخت‌های T1, …, Tk را دارد:
    • پیش‌ترتیب (preorder): Pre(T) = r, Pre(T1), …, Pre(Tk)
    • میان‌ترتیب (inorder): In(T) = In(T1), r, In(T2), …, In(Tk)
    • پس‌ترتیب (postorder): Post(T) = Post(T1), …, Post(Tk), r
  • هر پیمایش O(n) طول می‌کشد.
def preorder(node, out):
  if node:
    out.append(node.key)
    preorder(node.left, out)
    preorder(node.right, out)

def inorder(node, out):
  if node:
    inorder(node.left, out)
    out.append(node.key)
    inorder(node.right, out)

def postorder(node, out):
  if node:
    postorder(node.left, out)
    postorder(node.right, out)
    out.append(node.key)
  • پیش‌ترتیب در نمایش چپ‌ترین فرزند / برادر راست:
def preorder_tree(node, out):
  while node:
    out.append(node.key)
    preorder_tree(node.left_child, out)
    node = node.right_sibling

نگارش عبارت و درخت عبارت

  • نمایش متداول عبارت ریاضی (میان‌وندی) یکتا نیست و نیاز به پرانتزگذاری دارد. با اولویت دادن به عملگرها این مشکل تا حدی حل می‌شود، ولی وقتی ترتیب دیگری مدنظر باشد باید پرانتز بگذاریم.
  • نگارش‌های مختلف یک عبارت:
    • میان‌وندی (infix) با پرانتزگذاری کامل: (7 + 6)
    • پیش‌وندی (prefix): + 7 6
    • پس‌وندی (postfix): 7 6 +
  • یک عبارت ریاضی را می‌توان به صورت درخت عبارت نشان داد: عملگرها رئوس داخلی و مقدارها/متغیرها برگ‌ها هستند. پیمایش پیش‌ترتیب، میان‌ترتیب و پس‌ترتیب این درخت به ترتیب نگارش پیش‌وندی، میان‌وندی و پس‌وندی را می‌دهد.
  • قضیه برای درخت‌های مرتب: اگر نمایش پیش‌ترتیب یا پس‌ترتیب یک درخت را به همراه تعداد فرزندان هر رأس داشته باشیم، درخت به صورت یکتا مشخص می‌شود.
  • توجه کنید اگر درخت دودویی مدنظر باشد و فرزند چپ و راست با هم فرق داشته باشد، این قضیه دیگر درست نیست.
  • در درخت عبارت تعداد فرزندان هر رأس از نوع آن (عملگر یا مقدار) معلوم است، پس نگارش پیش‌وندی یا پس‌وندی عبارت را بدون نیاز به پرانتز مشخص می‌کند. مثال: a b + c d e + * * یعنی (a + b) * (c * (d + e)).
  • با داشتن درخت می‌توان کارهای پیچیده مثل مشتق‌گیری از عبارت را انجام داد. ساده‌ترین کار، محاسبۀ مقدار عبارت با پیمایش پس‌ترتیب است:
OPS = {'+': lambda a, b: a + b, '-': lambda a, b: a - b,
       '*': lambda a, b: a * b, '/': lambda a, b: a / b}

def evaluate(node):
  if node.key not in OPS:
    return node.key
  return OPS[node.key](evaluate(node.left), evaluate(node.right))
  • ساخت درخت عبارت از نگارش پس‌وندی با یک پشته: مقدارها را در پشته می‌گذاریم و با دیدن هر عملگر دو درخت بالای پشته را فرزندان آن می‌کنیم. (از نگارش پیش‌وندی هم به همین شکل، با خواندن از آخر به اول.)
def postfix_to_tree(tokens):
  S = []
  for t in tokens:
    if t in OPS:
      right = S.pop()
      left = S.pop()
      S.append(new_node(key=t, left=left, right=right))
    else:
      S.append(new_node(key=t, left=None, right=None))
  return S.pop()
  • ساخت درخت عبارت از نگارش میان‌وندی با پرانتزگذاری کامل: با هر ( یک فرزند چپ می‌سازیم و پایین می‌رویم، با هر عملگر برچسب رأس فعلی را می‌گذاریم و به فرزند راست جدید می‌رویم، با هر مقدار برچسب را می‌گذاریم و بالا می‌رویم و با هر ) بالا می‌رویم.
def paren_infix_to_tree(tokens):
  root = p = new_node(key=None, left=None, right=None, parent=None)
  for t in tokens:
    if t == '(':
      p.left = new_node(key=None, left=None, right=None, parent=p)
      p = p.left
    elif t == ')':
      p = p.parent
    elif t in OPS:
      p.key = t
      p.right = new_node(key=None, left=None, right=None, parent=p)
      p = p.right
    else:
      p.key = t
      p = p.parent
  return root
  • تبدیل میان‌وندی به پس‌وندی با یک پشته: مقدارها را مستقیم به خروجی می‌فرستیم. عملگرها را در پشته نگه می‌داریم و پیش از گذاشتن یک عملگر، عملگرهای بالای پشته را که اولویتشان بیشتر یا برابر است به خروجی می‌فرستیم. ( در پشته می‌رود و با دیدن ) تا رسیدن به ( از پشته بیرون می‌آوریم. زمان آن O(n) است.
PREC = {'+': 1, '-': 1, '*': 2, '/': 2}

def infix_to_postfix(tokens):
  out, S = [], []
  for t in tokens:
    if t == '(':
      S.append(t)
    elif t == ')':
      while S[-1] != '(':
        out.append(S.pop())
      S.pop()
    elif t in PREC:
      while S and S[-1] != '(' and PREC[S[-1]] >= PREC[t]:
        out.append(S.pop())
      S.append(t)
    else:
      out.append(t)
  while S:
    out.append(S.pop())
  return out
