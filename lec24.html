جست‌وجوی عمق اول (DFS)

  • مشابه حل باغ هزارتو (ماز)، یک مسیر را پیش می‌گیریم و از رفتن مسیر تکراری و قطع کردن مسیر خودداری می‌کنیم.
  • اگر به بن‌بست خوردیم، مسیر را تا جایی برمی‌گردیم که یک راه جدید باز شود.
  • اگر رأس‌هایی مانده بود که ندیده بودیم، جست‌وجو را از یکی از این رأس‌ها ادامه می‌دهیم.
def DFS(V, Adj):
  parent = {}
  def visit(u):
    for v in Adj[u]:
      if v not in parent:
        parent[v] = u
        visit(v)
  for s in V:
    if s not in parent:
      parent[s] = None
      visit(s)
  return parent
  • مثال اجرای DFS روی یک گراف.
  • یال‌های هر رأس به parent آن درخت DFS (در واقع جنگل DFS) را تشکیل می‌دهند.
  • زمان اجرا: visit برای هر رأس دقیقاً یک بار صدا زده می‌شود و هر visit به اندازۀ تعداد همسایه‌های آن رأس طول می‌کشد. بنابراین زمان اجرای جست‌وجوی عمق اول نیز Θ(n + e) است.
  • BFS مثل داده‌ساختار صف (رویکرد FIFO) رأس‌ها را پیمایش می‌کند و DFS مثل داده‌ساختار پشته (رویکرد LIFO).

زمان شروع و پایان و دسته‌بندی یال‌ها

  • زمان شروع start[u] لحظۀ صدا زدن visit(u) و زمان پایان finish[u] لحظۀ تمام شدن آن است. این زمان‌ها کاربردهای فراوانی دارند.
  • بازه‌های [start[u], finish[u]] یا تودرتو هستند یا جدا از هم: v از نوادگان u در درخت DFS است اگر و تنها اگر بازۀ v درون بازۀ u باشد.
  • دسته‌بندی یال‌های گراف، برای یال (u, v):
    • ۱. یال درخت: یال‌های درخت DFS (v اولین بار از همین یال دیده شد).
    • ۲. یال رو به جلو: از یک رأس به یکی از نوادگانش که یال درخت نیست.
    • ۳. یال بازگشتی: از یک رأس به یکی از اجدادش.
    • ۴. یال متقاطع: بقیۀ یال‌ها، بین دو رأس که هیچ‌کدام جد دیگری نیست.
  • در گراف‌های بدون جهت یال رو به جلو و متقاطع وجود ندارد. اثبات: اگر u زودتر دیده شود، v قبل از پایان visit(u) دیده می‌شود، پس v از نوادگان u است و یال یا یال درخت است یا (وقتی از سمت v دیده شود) یال بازگشتی.
def DFS_times(V, Adj):
  parent, start, finish = {}, {}, {}
  time = [0]
  def visit(u):
    start[u] = time[0]
    time[0] += 1
    for v in Adj[u]:
      if v not in parent:
        parent[v] = u
        visit(v)
    finish[u] = time[0]
    time[0] += 1
  for s in V:
    if s not in parent:
      parent[s] = None
      visit(s)
  return parent, start, finish

def edge_type(u, v, parent, start, finish):
  if parent[v] == u:
    return "tree"
  if start[u] < start[v] and finish[v] < finish[u]:
    return "forward"
  if start[v] <= start[u] and finish[u] <= finish[v]:
    return "back"
  return "cross"
  • (در گراف جهت‌دار؛ طوقۀ (u, u) را یال بازگشتی حساب می‌کنیم.)

کاربردهای جست‌وجوی عمق اول

  • پیدا کردن دور، بررسی دوبخشی بودن گراف، مرتب‌سازی توپولوژیکی گراف جهت‌دار بدون دور، مؤلفه‌های قویاً همبند گراف‌های جهت‌دار (جلسۀ ۲۵)، مؤلفه‌های دوهمبند گراف‌های بدون جهت، رأس‌ها و یال‌های برشی گراف‌های بدون جهت و …

پیدا کردن دور

  • گراف دور دارد اگر و تنها اگر در DFS یال بازگشتی وجود داشته باشد. این حکم هم در گراف‌های جهت‌دار و هم در گراف‌های بدون جهت برقرار است (در گراف بدون جهت، یال به خود parent را یال بازگشتی حساب نمی‌کنیم).
  • اثبات:
    • ⇐: یال بازگشتی (u, v) همراه با مسیر درختی از v به u یک دور است.
    • ⇒: یک دور دلخواه (v0, v1, …, vk) را درنظر بگیرید که v0 اولین رأس دیده‌شده از این دور در DFS باشد. اگر یال (vi, vi+1) در گراف باشد و vi+1 هنوز دیده نشده باشد، قبل از این‌که visit(vi) تمام شود visit(vi+1) اجرا می‌شود. پس قبل از پایان visit(v0)، visit(vk) اجرا می‌شود و vk از نوادگان v0 است. بنابراین یال (vk, v0) یک یال بازگشتی است.
  • در پیاده‌سازی، رأس‌هایی را که visit آن‌ها شروع شده و هنوز تمام نشده (روی پشتۀ بازگشت هستند) علامت می‌زنیم؛ یالی به چنین رأسی یال بازگشتی است:
def has_cycle(V, Adj):
  parent, active = {}, set()
  def visit(u):
    active.add(u)
    for v in Adj[u]:
      if v in active:
        return True  # back edge
      if v not in parent:
        parent[v] = u
        if visit(v):
          return True
    active.remove(u)
    return False
  for s in V:
    if s not in parent:
      parent[s] = None
      if visit(s):
        return True
  return False
  • این کد برای گراف جهت‌دار است. در گراف بدون جهت کافی است یال برگشت به parent[u] را نادیده بگیریم.

بررسی دوبخشی بودن

  • گراف بدون جهت دوبخشی است اگر بتوان رأس‌ها را با دو رنگ رنگ کرد طوری که دو سر هر یال رنگ متفاوت داشته باشند؛ یعنی اگر و تنها اگر دور فرد نداشته باشد.
  • در DFS (یا BFS) هر رأس را با رنگ مخالف parent آن رنگ می‌کنیم. گراف دوبخشی است اگر و تنها اگر هیچ یالی دو سر هم‌رنگ نداشته باشد.
def is_bipartite(V, Adj):
  color = {}
  def visit(u):
    for v in Adj[u]:
      if v not in color:
        color[v] = 1 - color[u]
        if not visit(v):
          return False
      elif color[v] == color[u]:
        return False
    return True
  for s in V:
    if s not in color:
      color[s] = 0
      if not visit(s):
        return False
  return True

مرتب‌سازی توپولوژیکی گراف جهت‌دار بدون دور

  • تعدادی کار داریم که بعضی پیش‌نیاز بعضی دیگرند. ترتیبی از کارها ارائه دهید که پیش‌نیاز هر کار قبل از آن اجرا شده باشد. این مسئله فقط برای گراف جهت‌دار بدون دور (DAG) جواب دارد.
  • تلاش ناموفق برای حل مسئله با BFS: ترتیب لایه‌ها لزوماً ترتیب پیش‌نیازها را رعایت نمی‌کند.
  • اگر رأس‌ها را بر اساس عکس ترتیب زمان پایان مرتب کنیم، نتیجۀ دلخواه به دست می‌آید.
  • اثبات: اگر یال (u, v) در گراف باشد، visit(v) قبل از پایان visit(u) اجرا و تمام می‌شود (چون گراف دور ندارد، v نمی‌تواند روی پشتۀ بازگشت باشد). پس finish[v] < finish[u] و u در ترتیب نهایی قبل از v می‌آید.
  • یک مثال از مرتب‌سازی توپولوژیک با این روش.
def topological_sort(V, Adj):
  parent, order = {}, []
  def visit(u):
    for v in Adj[u]:
      if v not in parent:
        parent[v] = u
        visit(v)
    order.append(u)  # u finishes
  for s in V:
    if s not in parent:
      parent[s] = None
      visit(s)
  return order[::-1]
  • زمان اجرای همۀ این کاربردها مثل خود DFS، Θ(n + e) است.
