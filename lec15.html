آدرس‌دهی باز

  • در آدرس‌دهی باز (open addressing) به جای زنجیره همۀ اشیا را در خود جدول ذخیره می‌کنیم. اندازۀ جدول را m ≥ 2n می‌گیریم.
  • دنبالۀ وارسی (probe sequence) شیء x: h(x, 0), h(x, 1), …, h(x, m − 1) که باید جایگشتی از خانه‌های جدول باشد.
  • درج: خانه‌ها را به ترتیب دنبالۀ وارسی نگاه می‌کنیم و x را در اولین خانۀ خالی درج می‌کنیم.
  • جست‌وجو: خانه‌ها را به ترتیب دنبالۀ وارسی نگاه می‌کنیم تا یا x را پیدا کنیم یا به یک خانۀ خالی برسیم که یعنی x در جدول نیست.
  • حذف دقت بیشتری می‌خواهد: اگر خانۀ شیء حذف‌شده را خالی کنیم، جست‌وجوهای بعدی ممکن است زودتر از موعد به خانۀ خالی برسند و درست کار نکنند. پس در خانه می‌نویسیم «حذف‌شده». خانۀ حذف‌شده در جست‌وجو مثل خانۀ پر و در درج مثل خانۀ خالی است. (البته قبل از درج باید جست‌وجو کنیم، وگرنه ممکن است یک کلید دو بار در جدول بیاید.)
  • اگر تعداد خانه‌های «حذف‌شده» به ۱۰ درصد جدول رسید، جدول را دوباره می‌سازیم. هزینۀ سرشکن هنوز O(1) می‌ماند.
  • در کد زیر وارسی خطی (پایین‌تر) و تابع universal_hash جلسۀ ۱۴ به کار رفته است. با عوض کردن خط محاسبۀ j روش‌های دیگر وارسی به دست می‌آیند.
DELETED = 'deleted'

def oa_new(m):
  return SimpleNamespace(m=m, n=0, d=0, h=universal_hash(m), slots=[None] * m)

def oa_rebuild(T, m):
  items = [s for s in T.slots if s is not None and s is not DELETED]
  T.m, T.n, T.d, T.h = m, 0, 0, universal_hash(m)
  T.slots = [None] * m
  for k, v in items:
    oa_insert(T, k, v)

def oa_search(T, k):
  for i in range(T.m):
    j = (T.h(k) + i) % T.m
    s = T.slots[j]
    if s is None:
      return None
    if s is not DELETED and s[0] == k:
      return s[1]
  return None

def oa_insert(T, k, v):
  free = None
  for i in range(T.m):
    j = (T.h(k) + i) % T.m
    s = T.slots[j]
    if s is None or s is DELETED:
      if free is None:
        free = j
      if s is None:
        break
    elif s[0] == k:
      T.slots[j] = (k, v)
      return
  if T.slots[free] is DELETED:
    T.d -= 1
  T.slots[free] = (k, v)
  T.n += 1
  if 2 * T.n > T.m:
    oa_rebuild(T, 2 * T.m)

def oa_delete(T, k):
  for i in range(T.m):
    j = (T.h(k) + i) % T.m
    s = T.slots[j]
    if s is None:
      return
    if s is not DELETED and s[0] == k:
      T.slots[j] = DELETED
      T.n -= 1
      T.d += 1
      if 10 * T.d >= T.m:
        oa_rebuild(T, T.m)
      return

روش‌های وارسی

  • وارسی خطی (linear probing): h(x, i) = (h′(x) + i) mod m.
    • مشابه پارک کردن ماشین در خیابان: اگر جا پر است، جای بعدی را امتحان می‌کنیم.
    • مشکل خوشه‌ها: خوشه دنباله‌ای از خانه‌های متوالی پر است. هر چه خوشه بزرگ‌تر باشد، احتمال رشد آن بیشتر است. خوشه‌هایی به اندازۀ Θ(log n) به وجود می‌آیند که زمان جست‌وجو و درج را زیاد می‌کنند.
    • ثابت شده است وارسی خطی با یک تابع درهم‌سازی ۵-مستقل خوب کار می‌کند و توابع ۴-مستقلی هستند که با آن‌ها بد کار می‌کند.
  • وارسی درجۀ دو (quadratic probing): h(x, i) = (h′(x) + a i2 + b i) mod m.
  • درهم‌سازی دوگانه (double hashing): h(x, i) = (h1(x) + i · h2(x)) mod m.
    • h2(x) و m باید نسبت به هم اول باشند تا دنبالۀ وارسی همۀ خانه‌ها را ببیند.
    • یک راه: m عدد اول و h2(x) بین 1 و m − 1. راه بهتر: m توانی از ۲ و h2(x) فرد.

فرض درهم‌سازی یکنواخت

  • با فرض درهم‌سازی یکنواخت ساده (جلسۀ ۱۴) اشتباه نشود.
  • فرض درهم‌سازی یکنواخت (uniform hashing): دنبالۀ وارسی هر کلید یکی از m! جایگشت ممکن است که تصادفی و مستقل انتخاب می‌شود.
  • به طور کامل درست نیست، ولی درهم‌سازی دوگانه تا حد خوبی به آن نزدیک است. تحلیل زمان آدرس‌دهی باز با این فرض در جلسۀ بعد می‌آید.

تطابق رشته‌ها

  • ورودی: دو رشتۀ s و t. هدف: پیدا کردن وقوع‌های s به عنوان زیررشتۀ t (کجا و چند بار).
  • کاربردهای فراوان دارد، مثل جست‌وجو در کل ایمیل‌ها یا دستور grep.
  • الگوریتم بدیهی همه‌جای t را امتحان می‌کند و زمان آن O(|s| · (|t| − |s| + 1)) = O(|s| · |t|) است.
  • الگوریتم‌های سریعی مثل KMP و بویر-مور با زمان O(|s| + |t|) وجود دارند، اما کمی پیچیده‌اند.
  • الگوریتم کارپ-رابین (Karp-Rabin) هم زمان مورد انتظار O(|s| + |t|) دارد و از درهم‌سازی استفاده می‌کند. بسیار ساده است و روش آن بسیار پرکاربرد است.

الگوریتم کارپ-رابین

  • مقدار h(s) را با h(t[i … i + |s| − 1]) به ازای iهای مختلف مقایسه می‌کنیم.
    • اگر نامساوی بودند، قطعاً s در این مکان از t نیامده است.
    • اگر مساوی بودند، به احتمال زیاد s در این مکان آمده است. روش محتاطانه: برای اطمینان دو رشته را مقایسه می‌کنیم. روش مبتنی بر اعتماد: فرض می‌کنیم برابرند.
  • اگر تابع درهم‌سازی مناسب باشد، احتمال خطا در هر مکان حدود 1/m است.
  • زمان اجرا O(|s| + |t| + (|t| − |s| + 2) · cost(h)) است، پس باید درهم‌سازی هر پنجره را در O(1) از روی پنجرۀ قبلی حساب کنیم.

درهم‌سازی چرخشی

  • واسط درهم‌سازی چرخشی (rolling hash) روی رشتۀ x این عملیات را دارد:
    • r(): مقدار h(x) را برگرداند.
    • r.append(c): حرف c را به انتهای x اضافه کند.
    • r.skip(c): حرف c را از ابتدای x حذف کند.
  • داده‌ساختار: رشتۀ x را یک عدد |x|رقمی u در مبنای a (تعداد حروف الفبا) در نظر می‌گیریم و با روش تقسیم درهم می‌کنیم: r() مقدار u mod p را برمی‌گرداند که p یک عدد اول تصادفی و به اندازۀ کافی بزرگ (حداقل در حدود |s| یا |t|) است.
  • داده‌ساختار خود u را نگه نمی‌دارد؛ فقط |x| و u mod p را نگه می‌دارد.
  • بعد از r.append(c): (u · a + c) mod p = [(u mod p) · a + c] mod p، که با اطلاعات موجود در O(1) حساب می‌شود.
  • بعد از r.skip(c): (u − c · a|x|−1) mod p = [(u mod p) − c · (a|x|−1 mod p)] mod p، که آن هم در O(1) حساب می‌شود (اگر a|x|−1 mod p را نگه داریم).
  • بنابراین الگوریتم کارپ-رابین در زمان O(|s| + |t|) اجرا می‌شود و احتمال خطای آن در هر مکان حدود 1/p است.
def rh_new(a=256, p=1000000007):
  return SimpleNamespace(a=a, p=p, h=0, size=0)

def rh_append(r, c):
  r.h = (r.h * r.a + ord(c)) % r.p
  r.size += 1

def rh_skip(r, c):
  r.h = (r.h - ord(c) * pow(r.a, r.size - 1, r.p)) % r.p  # a**(size-1) mod p can be kept to make this O(1)
  r.size -= 1

def karp_rabin(s, t):
  if len(s) > len(t):
    return []
  rs, rt = rh_new(), rh_new()
  for c in s:
    rh_append(rs, c)
  for c in t[:len(s)]:
    rh_append(rt, c)
  found = []
  for i in range(len(t) - len(s) + 1):
    if rs.h == rt.h and t[i:i + len(s)] == s:
      found.append(i)
    if i + len(s) < len(t):
      rh_skip(rt, t[i])
      rh_append(rt, t[i + len(s)])
  return found
